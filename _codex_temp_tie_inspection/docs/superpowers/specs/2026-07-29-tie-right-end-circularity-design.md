# 扎带右端缺角检测设计

## 目标

创建一个独立的 C#/.NET 8 WinForms Demo，不引用现有 TDJS-Vision 框架代码。程序加载现场图片后，在用户指定的右端检测区域内提取黑色扎带、切断左侧连接、获取逐个连通域，并输出每个右端端帽的圆度；圆度最低和低于判定阈值的区域以红色显示。

## 算法

1. 用户在原图上拖动框选右端检测区域，或通过数值框精确调整 ROI。
2. ROI 左边界本身作为切割线，只分析线右侧区域，从空间上切断扎带长条与左侧结构。
3. 对 B、G、R 三通道的最大值做黑色阈值判断：`max(B,G,R) <= 阈值`。这样红色标注框不会被当作黑色目标。
4. 用小尺寸闭运算连接黑色区域内的细碎空洞，再通过连通域面积、宽度和高度过滤背景噪声。
5. 连通域按垂直中心从上到下排序。每个连通域先根据二阶矩主轴旋正，再截取最右侧 `端帽宽高比 × 旋正后高度` 的端帽轮廓。
6. 标准轮廓圆度按 `4πA/P²` 计算，其中 A 是端帽轮廓面积，P 是端帽轮廓周长。
7. 由于平直截断有时会让标准轮廓更紧凑，另计算圆头匹配度：比较端头中部与上下边缘的向右凸出量。正常圆弧接近 1，平切或缺角明显下降，缺陷判定以此指标为主。

## 架构

- `IRightEndInspector`：检测接口，便于以后替换为其他 OpenCV 算法。
- `OpenCvRightEndInspector`：OpenCvSharp 实现，只负责图像算法。
- `InspectionParameters`：阈值、ROI、面积和端帽比例等参数。
- `InspectionResult` / `InspectionRegionResult`：二值图、标注图和逐区域指标。
- `MainForm`：文件选择、ROI 框选、参数编辑、结果表格和图像展示。
- 所有 WinForms 控件均声明并初始化在 `MainForm.Designer.cs`。

## 界面

界面左侧显示原图和可拖动 ROI，右侧显示检测标注图；顶部为“打开图片”“执行检测”和参数控件；底部表格逐行显示序号、位置、面积、端帽面积、周长、标准轮廓圆度、圆头匹配度、相对偏差和判定。所有可见文字使用简体中文。

原图、检测标注图和黑色二值图统一使用可缩放图像查看控件。鼠标滚轮以光标所在图像点为中心缩放，缩放范围为 10%～2000%；右键拖动平移，双击恢复适应窗口。原图左键仍专用于 ROI 框选。顶部提供“全部放大”“全部缩小”“全部适应”按钮，同时操作三块图像。

## 异常与性能

- 未加载图片、ROI 越界、参数非法时给出中文提示。
- Mat 和 Bitmap 明确释放，避免连续换图造成内存增长。
- 检测放到后台线程执行，避免窗体卡顿。
- 只处理 ROI，连通域和轮廓均为线性图像操作，适合现场快速调参。

## 测试与验收

- 单元测试验证圆形轮廓圆度高于缺角轮廓。
- 合成多行图测试验证从上到下排序和缺角项圆度最低。
- 样图集成检测应获得稳定的多行结果，底部异常区域应落入最低圆度组。
- `dotnet test` 和 `dotnet build` 均须成功。
