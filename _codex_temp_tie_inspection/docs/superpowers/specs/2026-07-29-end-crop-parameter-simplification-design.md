# 端头截取参数精简与最右可信纹理设计

## 目标

Demo 只保留“二值化提取黑色区域、打断连通域、统一扎带方向、定位最后一条纹路右侧并截取到圆头最右端”的流程。圆度、圆头匹配度和 OK/NG 判定全部退出本阶段，界面只显示与端头截取直接相关的参数和结果。

正确截取起点定义为：旋正且统一为圆头朝右后，最后一条可信竖向纹路的右侧边缘，也就是连续光滑黑色端头开始的位置。

## 界面参数

继续保留黑色区域提取必需参数：

- ROI X、ROI Y、ROI 宽度、ROI 高度。
- 黑色阈值。
- 最小面积、最小宽度、最小高度、最大高度。
- 闭运算核。

删除与圆头测量和缺陷判定有关的参数：

- 端帽比例。
- 圆头匹配阈值。
- 相对下降阈值。

新增两个端头截取参数，并把控件定义放在 `MainForm.Designer.cs`：

1. `纹理灵敏度`：范围 0～100，默认 60。数值越大，越容易把右侧较弱的最后几条纹路认作有效纹理；界面不暴露归一化置信度等内部术语。
2. `起点修正(px)`：范围 -100～100，默认 0。自动定位后沿旋正局部 X 方向微调；正数向圆头方向移动，负数向齿纹方向移动。修正结果必须限制在组件内部，并至少保留 3 像素端头。

## 定位算法

`TextureTransitionEndBoundaryLocator` 继续使用逐列亮度中位数、相邻列差分能量和 MAD 归一化，不恢复固定白纹亮度差。

当前实现选择全搜索范围内置信度最高的转折，因此弱的末端纹路可能被跳过，最终选择到更靠左但更强的转折。本次改为：

1. 把右侧光滑端头最小比例由内部常量 35% 调整为 25%，允许搜索位置继续向右，但仍排除圆头边缘高亮。
2. 使用“纹理灵敏度”映射可信转折的最低归一化置信度；灵敏度越高，最低门槛越低。
3. 收集所有达到门槛、且左侧纹理能量高于右侧光滑能量的候选。
4. 优先选择最靠右的可信候选，而不是全局置信度最高候选。
5. 在候选附近从右向左回查最后一个显著纹理沿，以其右侧作为自动起点。
6. 同图共识补齐完成后统一应用“起点修正”，保证局部定位和整体补齐行为一致。

方向统一、稳健同图直线拟合、MAD 离群排除和伪连通域过滤保持不变。

## 接口与结果模型

在 `InspectionParameters` 中删除：

- `EndCapWidthHeightRatio`
- `RoundCapScoreThreshold`
- `MaximumNegativeDeviationPercent`

新增：

- `TextureSensitivity`
- `EndBoundaryOffsetPixels`

纹理定位接口使用独立的端头定位选项对象接收灵敏度，避免定位器直接依赖 WinForms。最终偏移由检查器在局部定位或整体补齐之后统一应用。

在 `InspectionRegionResult` 中删除：

- 端帽面积、端帽周长。
- 圆度、圆头匹配度。
- 相对中位数偏差。
- 缺陷判定状态。

保留区域序号、连通域框、组件面积、端头边界、截取矩形、定位来源和坐标回映多边形。

结果表格删除端帽面积、端帽周长、圆度、圆头匹配度、相对偏差和判定列，只显示区域位置尺寸、区域面积、端头起点 X、端头裁剪宽度和定位来源。

## 测试与验收

1. 新增合成测试：在最强转折右侧再放置 2～3 条较弱纹路，修复前会选到强转折，修复后必须选到最后一条弱纹路右侧。
2. 新增灵敏度测试：低灵敏度允许忽略弱纹，高灵敏度必须识别弱纹，且数值方向与界面说明一致。
3. 新增起点修正测试：正负偏移正确生效，越界时安全限制并保留至少 3 像素端头。
4. 更新现有现场样图和 45 张 NG 文件夹测试，删除圆头指标断言，继续要求所有有效区域均有合法端头起点。
5. 批量输出每张图片的区域数、局部定位数、整体补齐数和裁剪宽度，重点复核用户截图所示的末端弱纹不再残留在截取图内。
6. 完整 Release 测试、Release 构建和 WinForms 启动检查必须通过；控件全部可在 WinForms 设计器中看到。

## 性能与异常处理

- 仍使用逐列一次扫描和前缀和，复杂度近似为 ROI 像素数线性级别。
- 不为每个候选创建图像副本，新增参数不引入额外 `Mat` 生命周期。
- 参数进入检测前校验范围；偏移统一裁剪到合法坐标，单根失败不会中断其他区域。
- 所有新增属性、字段、方法、类和接口继续使用简体中文注释。
