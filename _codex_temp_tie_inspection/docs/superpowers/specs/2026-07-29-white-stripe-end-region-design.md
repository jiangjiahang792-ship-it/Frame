# 扎带最右白纹端头区域提取设计

## 目标

在用户框选的大 ROI 内二值化提取全部黑色扎带，通过 ROI 左边界打断长条连通域。对每个有效连通域单独预处理，找到最右侧内部白色竖纹，并从该白纹的右边缘裁剪到扎带外轮廓最右端。程序把所有裁剪结果按从上到下的序号集中显示，供用户先确认端头定位效果。

## 本阶段范围

- 保留大 ROI 框选、黑色二值化、连通域过滤、从上到下排序、图像缩放和平移。
- 保留连通域默认最大高度 `60`，兼容 3072×2048 现场图中的倾斜扎带。
- 取消斜切角参与缺陷判定，并移除斜切角参数、结果列和标注文字，避免本阶段被旧判定干扰。
- 原有圆度和圆头匹配度暂时保留，仅作观察；本阶段验收对象是白纹定位和端头裁剪效果，不重新制定 OK/NG 规则。
- 不引入模板文件、机器学习模型或 TDJS-Vision 当前框架代码。

## 裁剪边界定义

每根扎带先按自身主轴旋正，再在旋正后的局部坐标系内定位和裁剪：

- 左边界：最右侧有效白色竖纹的右边缘之后第一个像素列。
- 右边界：当前扎带外轮廓的最右端。
- 上边界和下边界：旋正后当前扎带连通域的完整高度。
- 最终显示原始彩色图对应的旋正端头区域；二值图用于限定扎带掩膜，彩色图用于保留低于全局阈值的相对亮纹。

## 白纹定位算法

采用“二值掩膜 + 彩色局部对比”的列投影，不使用白色连通域或固定模板：

1. 对单根扎带的二值掩膜做水平旋正并紧密裁剪。
2. 取连通域高度中间的 50% 作为投影带，避开扎带上下外轮廓和圆头弧线。
3. 先逐列统计黑色前景占投影带高度的比例；二值图中存在真实空隙时，低前景占比的连续列直接作为白纹候选。
4. 若肉眼可见的亮纹仍低于全局黑色阈值，则计算彩色图每列最大通道均值，并比较候选列与左右暗部的局部亮度差；默认最小相对对比度为 `40`。
5. 候选纹路必须位于黑色主体内部，左右两侧都存在连续黑色列，并具有足够长的右侧端头，排除图像边界、圆头外部背景、弱亮度缓变和孤立噪声。
6. 候选宽度按连通域高度归一化过滤，避免把单像素锯齿或大块背景当成纹路。
7. 从全部有效候选中选择 X 坐标最大的一个，得到“最右侧白纹”。
8. 若未找到有效白纹，不用猜测位置，也不回退到斜切角；该区域标记为“未找到白纹”，预览中显示占位提示。

列投影只访问每个连通域的局部掩膜，复杂度与 ROI 像素数近似线性，适合连续运行。

## 组件与数据流

### 检测服务

`OpenCvRightEndInspector` 继续实现 `IRightEndInspector`，内部增加三个职责明确的方法：

- `IRightmostWhiteStripeLocator.TryLocate`：输入旋正二值连通域和彩色连通域，输出白纹局部矩形或未找到。
- `ExtractEndRegion`：使用白纹右边缘裁剪旋正后的彩色连通域。
- `BuildEndRegionPreview`：把各端头裁剪图按序号纵向排列成一张预览图。

旋正过程同时作用于二值掩膜和彩色局部图，二者使用同一仿射矩阵和紧密裁剪矩形，确保白纹坐标与彩色裁剪图一一对应。
旋正结果同时保存逆变换所需的数据，把白纹矩形和端头裁剪矩形的四个角准确映射回原图，供标注图绘制倾斜多边形。

### 结果模型

`InspectionRegionResult` 增加：

- 是否找到最右白纹。
- 白纹在旋正局部图中的矩形。
- 最终端头裁剪矩形。
- 映射回原图的白纹四边形和端头四边形。

`InspectionResult` 增加一张需要随结果释放的端头预览 `Mat`。每个区域的临时 `Mat` 在预览拼接后立即释放，不长期保存在行模型中。

### 界面

所有新增控件都写入 `MainForm.Designer.cs`：

- 结果页签增加“端头提取图”。
- 页签内使用现有 `ZoomableImageBox`，支持滚轮缩放、右键拖动和双击适应窗口。
- 执行检测后默认切换到“端头提取图”。
- 预览图中每行只显示序号、红色左边界线，以及从白纹右边缘到最右端的彩色端头区域。
- 表格增加“白纹 X”“裁剪宽度”“白纹状态”三列。
- 状态栏显示“检测到 N 根，成功提取 M 个端头，未找到白纹 K 个”。

原标注图继续显示连通域外框，并用青色四边形标出白纹、红色四边形标出最终端头区域；四边形由旋正仿射矩阵的逆变换计算，不使用比例近似。

## 错误处理

- 无有效连通域：显示现有参数调整提示，并生成空预览。
- 某根未找到白纹：不影响其他扎带，表格标记“未找到”，预览显示该根完整旋正图和提示。
- 裁剪宽度小于 3 像素：视为无效白纹，不生成错误尺寸的 OpenCV ROI。
- 所有 `Mat` 和 `Bitmap` 均沿用当前释放模式，避免重复检测后的非托管内存增长。

## 测试设计

1. 合成水平扎带：包含多个白色竖纹，验证选择最右侧内部白纹，并从其右边缘裁到最右端。
2. 边界排除：圆头右侧背景虽然为白色，但没有右侧黑色支撑，不得被识别为内部白纹。
3. 无白纹扎带：返回未找到，不抛异常，不生成非法裁剪矩形。
4. 多行扎带：验证结果仍从上到下排序，预览包含相同数量的编号行。
5. 现场样图：验证大 ROI 能提取 25 根扎带，并为全部 25 个区域找到白纹；逐区域裁剪宽度均为正且右边界等于对应旋正连通域最右端；前 24 根宽度保持在 `195～215` 像素，防止误选端头弱亮度缓变。
6. 现有缩放、旧样图和连通域测试全部继续通过。

## 验收标准

- 用户在原图画一个大 ROI 后，一次检测即可处理全部扎带。
- 每根预览的红色起始线位于最右侧白纹右边缘。
- 每根显示区域从该起始线连续延伸到外轮廓最右端，并保留完整扎带高度。
- 3072×2048 现场图提取的 25 根扎带全部成功找到最右白纹，不允许静默漏掉某一根。
- 新页签能放大、缩小和平移，序号与表格区域一一对应。
- 本阶段不依赖斜切角给出端头位置或 OK/NG 结论。
- Release 测试全部通过，构建为 0 警告、0 错误，WinForms 可正常启动。
