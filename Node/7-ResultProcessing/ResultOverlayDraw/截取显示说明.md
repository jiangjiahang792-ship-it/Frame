# ROI结果绘制：截取显示

1. 订阅并运行输入图像节点，在“ROI结果绘制”右侧点击“绘制截取ROI”。界面会显示输入原图，自动启用“截取显示”。
2. 移动、缩放或旋转蓝色矩形，然后点击“确认截取ROI”。也可以调整后直接点击“预览”，自动读取当前矩形。
3. 点击“预览”检查截取结果，再保存参数。重新绘制时始终回到输入原图，不会在上一次截取图上累计偏移。
4. 关闭“截取显示”后预览或运行，恢复原来的完整图像及显示逻辑，已保存的截取框保留，便于再次启用。旧方案默认关闭此功能。

截取先按矩形自身角度转正，再应用节点原有的0、90、180、270度输出旋转。图像与检测框、NG框、线、圆、圆弧、椭圆、轮廓和绝对图像坐标文字锚点使用同一仿射变换；文字保持正向可读，字号不变。

四角锚定文字在新图像边界重新排版；控件坐标文字仍以显示控件边界定位。图像坐标标注裁切在截取图像内，控件坐标文字不受该裁切限制。只移动输出显示副本，不修改上游结果、检测数值或判定。

输出保留每像素比例，不额外缩放。矩形部分超出输入图像时，超出部分补黑；完全没有交集或参数无效时明确报错。图像显示控件的正常缩放会同步缩放标注。输出图像仍可供图像显示、命名存图等下游节点订阅。
