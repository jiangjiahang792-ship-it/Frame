# 组合颜色识别

算法移植自用户指定的“四芯线软件”左右转线组合模式：主色筛选、四种颜色空间学习、环形色相阈值、灵敏度扩展、5×5 闭运算及八连通区域分析。新增面积过滤、全部识别结果输出和框架位置跟随，未修改原颜色识别节点。

## 使用步骤

1. 在工具箱添加“组合颜色识别”，订阅彩色图像并刷新。
2. 点击“绘制颜色ROI”，拖动、旋转橙色小框覆盖目标颜色，再点击“学习颜色”。取色框单独保存，不会覆盖搜索区域。取色框含有相近占比的不同颜色时会提示缩小框，防止误学背景。
3. 选择 HSV、HSI、LAB 或 RGB。一次学习保存四种模型，切换不需要重新学习。灵敏度默认 50，与参考软件默认值一致。
4. 不勾选“搜索区域”时识别全图；勾选后点击“绘制搜索ROI”调整蓝色搜索框，再点击“确认搜索ROI”。搜索框与取色框独立，重新绘制只调整对应框。搜索区域数值默认隐藏，点击“矩形参数设置”才展开。
5. 搜索区需要随工件移动时，勾选“位置跟随”，订阅位置修正结果，在当前图像上确认搜索区。记录绘制时的修正基准，运行时转换到新的位置和角度；上游定位失败时节点报错。
6. 设置最小面积和输出区域模式，点击“执行”核对，再点击“确定”保存。

## 输出含义

- 面积单位为像素²；在颜色分割、闭运算及搜索区裁剪之后，删除面积严格小于阈值的连通区域，等于阈值保留。
- 最大模式只输出面积最大的区域；全部模式输出全部通过筛选的区域，按面积降序排列，同面积按标签顺序排列。
- “区域个数”为最终输出个数；“总面积”为输出区域实际像素面积总和，孔洞不计入面积。
- 区域面积、长度、宽度列表按同一顺序对应。长度和宽度为最小旋转外接矩形的长边与短边，单位像素，基于像素中心坐标测量。例如实心 20×10 像素矩形，面积为 200、长度为 19、宽度为 9。
- 最大区域长度和宽度是列表首项，空结果返回零；空列表表示没有通过筛选的区域。是否合格由下游条件节点按工艺要求判断。
- “筛选后区域掩膜”保留原图尺寸，可供存图及后续处理；“算法结果”提供数量、总面积和各区域旋转框，可订阅绘制。
- 每个节点学习一种目标颜色；不同目标颜色可配置多个节点。

## 验证

Release/x64 隔离构建成功。`Tests/CombinationColor.Tests.ps1` 在真实程序集执行 25 项断言，覆盖四空间学习识别、红色色相跨零、混色拒绝学习、面积边界、最大/全部、孔洞、旋转长宽、ROI 裁剪、平移旋转跟随、避免重复仿射、定位失败、保存恢复及设计器窗体构造。未连接现场相机验证颜色与光照适应性。
