# 123方案迁移说明

## 已完成

- 原始123.Sol未覆盖。新版文件为123_新版轮廓模板匹配.Sol。
- 保留7个流程、154个节点及全部连线、节点编号、名称、位置、启用状态和设备配置。
- 15个MatchTemplate替换为ContourMatch，内嵌模板图片原样保留，9份PNG涂抹蒙版转为新版局部遮罩。
- 保留原图像订阅、匹配分数门槛、最大匹配个数、角度范围、重叠率和搜索区域；矩形边界向外取整，避免缩小原搜索范围。
- 新算法通常采用3层建模、2层搜索、平衡模式与亚像素精修；上线圈、下线圈采用自动特征、1层、最小对比度0并关闭亚像素，解决重复条纹在默认设置下自身漏检，分数门槛仍为0.83。
- 15个模板均通过真实新版节点离线自身匹配，分数约0.93～1.00；未连接现场相机或PLC，未验证现场产品检测准确率。
- 旧算法的粗匹配、轮廓显示开关不能与新算法一一对应，采用新版运行模式和显示行为；位置修正基准与下游订阅原样保留。
