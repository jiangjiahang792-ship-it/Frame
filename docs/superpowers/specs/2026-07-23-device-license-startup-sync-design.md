# 设备许可证启动自动同步设计

## 目标

主程序每次取得单实例运行权后，以程序运行目录根部的 `device.license` 为唯一许可证来源，自动检查并同步大模型、无监督和 YOLO GPU 的许可证副本。许可证缺失、目标目录未部署或复制失败时，主程序仍然正常启动，只写入简体中文日志。

## 范围

- 保留程序运行目录根部的 `device.license`，继续供 CPU YOLO 运行库使用。
- 自动同步到已经存在的 `LargeModelDll`、`UnsupervisedDll` 和 `YoloGPUDll` 运行目录。
- YOLO GPU 的 native DLL 位于 `YoloGPUDll\1050tidll` 与 `YoloGPUDll\750dll`，因此两个已存在的显卡专用目录也作为同步目标。
- 不复制大型运行库，不把 `LargeModelDll`、`UnsupervisedDll` 或 `YoloGPUDll` 绑定为项目生成内容。
- 不读取、解析、输出或修改许可证内容，日志不得包含许可证内容。
- 增加自动化回归测试，并更新 `任务记录.md`。

## 设计

### 同步服务边界

在 `Startup` 目录新增 `IDeviceLicenseSynchronizer` 接口与 `DeviceLicenseSynchronizer` 默认实现。接口接收程序运行目录，返回本次同步产生的结构化结果；文件系统检查、内容比较和复制逻辑全部封装在服务内，`Program` 只负责调用并写日志。

同步结果至少区分以下状态：

- 已复制：目标许可证原来不存在，或者内容与源文件不同，已经完成覆盖。
- 无需更新：目标许可证与源文件内容一致，没有重复写磁盘。
- 已跳过：目标运行目录不存在，说明对应运行环境当前没有部署。
- 失败：源许可证不存在、路径无效或目标复制发生异常。

新增的接口、类、枚举、属性、字段和方法均添加简体中文 XML 注释；关键路径判断和“不阻止启动”的思路添加简体中文注释。

### 唯一源文件与同步目标

源文件固定为：

```text
{AppDomain.CurrentDomain.BaseDirectory}\device.license
```

同步目标固定为：

```text
{运行目录}\LargeModelDll\device.license
{运行目录}\UnsupervisedDll\device.license
{运行目录}\YoloGPUDll\device.license
{运行目录}\YoloGPUDll\1050tidll\device.license
{运行目录}\YoloGPUDll\750dll\device.license
```

目标目录只有在已经存在时才参与复制。同步器不会为了许可证创建缺少的运行库目录，避免产生看似已部署、实际缺少 DLL 的空目录。

### 启动顺序

`Program.Main` 仍先获取单实例互斥锁。只有获得运行权的主进程才进入 `RunApplication`，并在创建启动上下文及加载任何 AI 模型前执行许可证同步。重复启动的第二个进程不会复制文件或写同步日志。

同步入口使用 `AppDomain.CurrentDomain.BaseDirectory`，不依赖当前工作目录，确保从快捷方式、命令行或其他程序启动时使用同一个发布目录。

### 内容比较与性能

许可证文件很小，但每次启动仍避免无意义覆盖：

1. 目标文件不存在时直接复制。
2. 文件长度不同时直接覆盖。
3. 文件长度相同时按字节比较；完全一致则跳过写入。
4. 内容不同则先在目标目录写入唯一临时文件；目标已存在时使用 `File.Replace` 原子替换，目标不存在时使用同目录 `File.Move` 原子落位。
5. 复制或替换失败时清理临时文件，保留原有目标许可证。

该策略保证替换根目录许可证后，下次启动会自动更新所有已部署目标，同时减少磁盘写入和文件占用冲突。

## 错误处理与日志

- 根目录缺少 `device.license`：记录一条中文警告，结束本次同步，继续启动。
- 某个目标目录不存在：记录中文信息并跳过，不创建目录。
- 某个目标复制失败：捕获该目标的异常，记录目标路径和异常信息，然后继续处理其他目标。
- 覆盖目标失败：不得原位截断旧许可证，原有目标文件保持可用。
- 同步服务整体发生未预期异常：`Program` 在最外层捕获并记录中文异常日志，继续后续启动流程。
- 同步成功或无需更新：记录中文信息，便于确认实际部署状态。
- 所有日志只包含同步状态、路径和异常信息，不输出许可证内容。

任何许可证同步结果都不得弹出消息框、抛到主启动链或阻止 `StartupApplicationContext` 创建。

## 测试与验证

新增自动化测试覆盖真实临时目录中的文件行为：

- 源许可证存在且目标缺失时，目标得到相同内容。
- 目标内容过期时，下次同步自动覆盖。
- 目标内容一致时，不重复写入。
- 目标运行目录不存在时，不创建空目录并返回跳过结果。
- 根目录源许可证不存在时，返回失败结果且不抛出异常。
- 一个目标失败时，其它可写目标仍继续同步。
- 已有目标被占用而替换失败时，旧许可证内容保持不变且不残留同步临时文件。
- `Program` 在单实例互斥锁之后、启动上下文之前调用同步器，并把所有结果写入日志。
- 项目文件只编译新增源码，不绑定或复制三个大型运行库目录。

实施时遵循测试先行：先运行新增测试并确认因同步功能不存在而失败，再编写最小实现使其通过。最后运行许可证专项测试、启动相关回归测试、运行库模板测试、`git diff --check` 和解决方案构建。
