# AI训练样本分类与目录追加设计

## 目标

统一完善无监督训练窗口和大模型训练窗口的样本目录加载行为。两个窗口都支持“默认、OK、NG”三种实际类别；默认图片保留在检查界面中，但绝不进入训练数据集。用户既可以选择一个主目录进行结构化分类，也可以向现有列表追加指定类别的整个样本目录。

## 交互设计

### 选择路径

1. 用户点击“选择路径”并选择一个主目录。
2. 程序检查主目录的直属子目录，目录名与 `OK`、`NG` 比较时不区分大小写。
3. 只要至少存在一个 `OK` 或 `NG` 直属子目录，就采用结构化分类：
   - `OK` 目录及其全部下级目录中的支持图片归入 OK。
   - `NG` 目录及其全部下级目录中的支持图片归入 NG。
   - 主目录根部及其他目录中的支持图片归入默认。
4. 如果两个标准目录都不存在，则弹出中文类别选择窗口，由用户选择“加入OK样本”“加入NG样本”或“取消”。选择 OK/NG 后，主目录及其全部下级目录中的支持图片统一归入对应类别；取消时保持当前图片列表和路径不变。
5. 选择成功后替换当前图片列表，并记录主目录供本次软件运行期间恢复。若目录没有标准 OK/NG 结构，还要同时记录用户选择的整批 OK/NG 类别；关闭后在本次软件运行内重新打开窗口时直接按原类别恢复，不再次弹出类别选择窗口。

### 追加样本目录

无监督和大模型窗口左侧分类区都增加以下两个按钮，控件必须声明并布局在对应 `.Designer.cs` 文件中：

- “添加OK样本目录”
- “添加NG样本目录”

按钮弹出文件夹选择窗口，递归读取所选目录中的支持图片，并强制归入按钮对应的类别。追加操作不清空当前列表、不修改顶部主路径、不移动或修改源文件，也不进行重复路径过滤；同一图片重复追加时保留多个样本项，并在训练数据集内生成不同的序号文件名。

### 分类与人工调整

左侧筛选区显示“全部、默认、OK、NG”及各自数量。底部图片操作区显示“设默认、设OK、设NG”三个按钮。用户把图片设为默认后，图片继续显示和预览，但从训练输入中排除。

颜色约定如下：

- 默认：灰色。
- OK：绿色。
- NG：红色。
- 当前选中项继续使用选中高亮色，类别色作为非选中边框或标识色。

## 组件职责

### 目录分类服务

新增可替换的目录分类接口及默认实现，负责：

- 识别支持的图片扩展名。
- 判断主目录是否具有标准 OK/NG 直属子目录。
- 输出每个图片路径及其默认、OK、NG 分类。
- 支持由调用方强制指定整批 OK 或 NG。
- 保持稳定、不区分大小写的路径排序。

目录分类服务只处理路径和分类，不创建位图和控件，便于独立测试以及后续替换目录规则。

### 图片加载器

现有无监督和大模型图片加载器继续负责从分类结果创建各自的图片项和缩略图。缩略图生成在后台任务中执行；损坏或无法读取的图片跳过并记录结果，不中断整批加载。

### 训练窗体

两个训练窗体负责：

- 调用目录分类服务和图片加载器。
- 在界面线程更新筛选、数量、卡片和预览。
- 选择主路径时替换列表，追加目录时只追加新项。
- 切换默认、OK、NG 分类。
- 管理取消令牌，避免关闭窗口后继续更新控件。

追加目录不重新生成已有图片的缩略图；界面只为新增且符合当前筛选条件的样本创建卡片，降低大目录追加时的重复工作。

### 类别选择窗口

新增可复用的 WinForms 类别选择窗口，所有标签和按钮使用简体中文，控件放入其 `.Designer.cs` 文件。窗口只返回 OK、NG 或取消，不提供默认选项，因为该窗口仅在所选主目录缺少标准 OK/NG 结构时用于确定整批训练类别。

### 训练服务

无监督和大模型训练服务必须采用类别白名单：

- 仅 OK 图片写入训练数据集的 `OK` 目录。
- 仅 NG 图片写入训练数据集的 `NG` 目录。
- 默认图片直接跳过，不复制、不裁剪，也不计入训练数量。

不得继续使用“不是 NG 就当作 OK”的判断。训练请求仍要求至少存在一张有效 OK 图片；仅有默认或 NG 图片时阻止训练并显示中文提示。

## 数据流

1. 用户选择主目录或追加样本目录。
2. 目录分类服务扫描路径并产生路径分类结果。
3. 图片加载器在后台生成对应图片项和缩略图。
4. 训练窗体更新列表、筛选数量和预览。
5. 用户可通过“设默认、设OK、设NG”调整单张图片。
6. 开始训练时，训练服务只选取 OK/NG 图片构建临时数据集，默认图片留在界面但不参与后续训练。

## 异常与边界处理

- 用户取消文件夹或类别选择时不改变现有状态。
- 目录不存在或无支持图片时显示中文提示，不清空当前有效列表。
- 只有一个标准目录时仍采用结构化分类；另一个类别数量为零，其他图片归入默认。
- 标准目录内部允许任意层级子目录，分类继承最外层标准目录。
- 重复添加图片是明确允许的行为，不显示重复警告。
- 损坏图片跳过；成功数、跳过数写入界面日志和软件日志。
- 默认图片不能因为筛选切换、重新渲染或训练请求组装而变成 OK。

## 验证

### 分类行为

- 同时存在 OK、NG 和其他目录时，三类计数正确。
- 仅存在 OK 或仅存在 NG 时采用结构化分类，其他图片进入默认。
- 标准目录名称大小写不同时仍能识别。
- 不存在标准目录时，整批选择 OK、整批选择 NG 和取消三种行为正确。

### 追加与人工调整

- 追加 OK/NG 目录只增加对应类别，不清空已有列表或改变主路径。
- 同一目录重复追加两次后样本数量增加两次。
- “设默认、设OK、设NG”能够正确更新分类、筛选和数量。

### 训练安全

- 两个训练服务构建数据集时都跳过默认图片。
- 默认图片即使位于可访问路径也不会被复制或裁剪。
- 训练数量和日志只统计 OK/NG；没有 OK 时继续阻止训练。

### 界面与回归

- 新按钮、默认筛选和“设默认”控件均存在于两个 `.Designer.cs` 文件并可在设计器查看。
- 执行专项回归检查以及解决方案 `Debug|x64` 编译。
- 保持现有 ROI、模板输出、训练取消和窗口资源释放行为不变。
