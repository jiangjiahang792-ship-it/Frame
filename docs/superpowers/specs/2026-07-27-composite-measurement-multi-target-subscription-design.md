# 复合测量工具多目标订阅统一设计

## 目标

将线到线夹角、点到点距离和点到区域距离的订阅模式统一为点到线距离现有规则，避免上游包含多个模板目标时只读取第一个摘要结果。

## 配对规则

- 双方均为多目标时，只按 `TargetIndex` 一一配对，不依赖集合下标或执行顺序。
- 一侧只有一个结果、另一侧包含多个目标时，将单结果作为公共基准广播到另一侧的全部目标。
- 双方均为多目标但某个编号缺失时，保留该目标编号并输出数值0、单项NG。
- 任一输入项自身为NG或无法提取所需几何数据时，保留该目标编号并输出数值0、单项NG。
- 全部目标均成功时节点总体OK；任一目标失败时节点总体NG。
- 上游没有多目标 `Items` 时继续读取原有摘要结果并作为目标1，兼容旧方案。

## 实现边界

- 复用 `MultiTargetMeasurementPairer` 和串行的 `MultiTargetMeasurementRunner`，不新增并发调度。
- 在公共测量结果读取器中增加从单个多目标明细读取线点集和区域轮廓的入口。
- 线到线保留每条线的边缘点，确保平均线距、最小线距、最大线距等统计行为不退化。
- 只修改订阅模式；绘制ROI与位置修正路径保持不变。
- 不修改WinForms控件及设计器文件。

## 验证标准

- 三个工具源码均通过 `PairByTargetIndex` 执行订阅多目标配对。
- N+N、N+1、1+N继续复用已验证的公共配对器行为。
- 线到线能够从单目标明细读取直线和对应边缘点。
- 点到区域能够从单目标明细读取区域轮廓。
- 相关多目标回归检查通过，完整解决方案编译为0个错误。
