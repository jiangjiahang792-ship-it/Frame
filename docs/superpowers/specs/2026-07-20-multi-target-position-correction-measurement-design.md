# 多目标位置修正与测量设计

## 1. 目标

当模板匹配一次找到多个目标时，位置修正节点应输出与目标一一对应的位姿变换集合。所有支持位置修正的测量工具只保存并编辑一套基准 ROI，运行时把该 ROI 分别变换到所有目标上独立测量，并输出与目标数量一致的测量结果集合。

本次覆盖以下测量工具：

- 卡尺找线；
- 卡尺找圆；
- 卡尺找椭圆；
- 找点；
- 线线角度；
- 点点距离；
- 点线距离；
- 点区域距离。

## 2. 已确认的业务规则

1. 模板匹配的全部有效结果都进入后续位置修正，不再只输出第一个结果的坐标和角度。
2. 位置修正默认使用模板匹配结果中的第一个目标创建基准。
3. 测量参数界面始终只存在一个可编辑 ROI，不为多个目标创建多个可拖动 ROI。
4. 用户可以把唯一的 ROI 绘制在任意一个已匹配目标附近。保存或点击运行时，系统自动识别 ROI 所属目标，并把 ROI 逆变换到统一基准坐标系。
5. 运行时把统一基准 ROI 分别变换到每个当前目标上执行测量。
6. 输出结果数量必须与输入目标数量一致，目标序号和模板匹配结果顺序一致。
7. 单个目标测量失败时保留该目标的结果项，所有数值型测量值写入 `0`，成功标记为 `false`，并记录简体中文失败原因。
8. 没有目标或任意一个目标测量失败时，测量节点总体状态为 NG；其他成功目标的结果仍正常保留和显示。
9. 当前模板匹配模型没有尺度搜索能力，因此每个目标输出 `ScaleX = 1.0`、`ScaleY = 1.0`。读取到小于或等于 `0` 的尺度时按 `1.0` 防御性处理。
10. 本次允许完整升级结果结构，不要求保留原有“第一个结果单值输出”的兼容语义。

## 3. 不在本次范围内

- 不修改 `MatchTool.dll`，也不在本次增加真正的多尺度模板搜索。
- 不实现非等比例尺度导致的圆形到椭圆形工具自动切换。
- 不扩展测量工具的“订阅几何结果”模式。本次多目标展开只作用于“绘制模式＋启用位置修正”的路径；原有订阅模式保持现状。
- 不在编辑状态下显示多个可编辑或静态复制 ROI。多目标变换只在运行时发生，界面显示多目标测量结果叠加层。

## 4. 数据模型

### 4.1 模板目标位姿

新增公共的模板目标位姿类型 `TemplateMatchPose`，包含：

- `TargetIndex`：从 1 开始的目标序号；
- `CenterX`、`CenterY`：目标中心；
- `Angle`：目标角度；
- `ScaleX`、`ScaleY`：目标尺度，当前固定为 `1.0`；
- `Score`：匹配得分；
- `Width`、`Height`：模板匹配框尺寸，用于 ROI 所属目标判断；
- `IsValid`：位姿是否有效。

`NodeResultMatchTemplate` 改为输出 `List<TemplateMatchPose> Poses`。`MatchCount` 由列表数量得到。旧的 `MatchX`、`MatchY`、`Angle`、`Score` 单值结果不再作为位置修正的数据入口。

### 4.2 多目标位置修正

位置修正参数改为订阅模板匹配的 `Poses` 集合。创建基准时读取第一个有效目标并保存其中心、角度和尺度。

新增 `MultiTargetPositionCorrectionResult`，包含：

- `BasePose`：创建基准时保存的第一个目标位姿；
- `Items`：当前每个目标对应的 `PositionCorrectionInfo` 集合；
- `Count`：当前有效目标数量；
- `IsValid`：基准有效且当前至少存在一个目标时为 `true`。

扩展 `PositionCorrectionInfo`，增加目标序号、基准尺度、当前尺度、匹配框和得分。所有属性、字段、方法、类和接口均添加简体中文 XML 注释。

### 4.3 测量结果集合

每个测量节点新增对应的目标结果项，例如：

- `CaliperLineTargetResult`；
- `CaliperCircleTargetResult`；
- `CaliperEllipseTargetResult`；
- `FindPointTargetResult`；
- `LineLineAngleTargetResult`；
- `PointPointDistanceTargetResult`；
- `PointLineDistanceTargetResult`；
- `PointRegionDistanceTargetResult`。

所有目标结果项实现公共接口 `IMultiTargetMeasurementItem`，至少包含：

- `TargetIndex`；
- `IsOk`；
- `ErrorMessage`；
- `Pose`；
- 当前目标变换后的 ROI 或几何信息。

各节点结果类使用 `Items` 集合输出全部目标结果，并保留节点级 `IsOk`、`RunTime`、`OutputImage` 和合并后的绘制结果。各类特有测量数值放在对应目标结果项中。失败项的所有数值型测量字段统一写入 `0`。

## 5. 公共变换服务

新增可替换接口 `IMultiTargetTransformService` 及默认实现 `MultiTargetTransformService`，统一负责：

1. 对小于或等于 `0` 的尺度规范化为 `1.0`；
2. 根据基准位姿和当前位姿构造二维变换；
3. 正向变换点、线段、区域和 ROI；
4. 逆向变换用户绘制的 ROI；
5. 判断唯一编辑 ROI 属于哪个当前目标。

当前模板输出尺度均为 `1.0`，因此实际效果是旋转和平移。接口仍携带 `ScaleX`、`ScaleY`，为后续替换支持尺度搜索的模板匹配器保留扩展点。

ROI 归属判断规则如下：

1. 计算 ROI 的几何中心；
2. 若中心落在某个旋转匹配框内，优先选择该目标；
3. 若同时落入多个框，选择中心距离最近的目标；
4. 若没有落入任何框，选择中心距离最近的目标；
5. 没有有效目标时显示简体中文错误并拒绝保存或运行。

识别所属目标后，使用该目标对应的逆变换把 ROI 转换到第一个基准目标的坐标系。参数文件只保存这一套标准 ROI，不保存编辑时所属目标的序号，避免下一帧匹配顺序变化影响运行。

## 6. 参数界面行为

### 6.1 位置修正界面

位置修正窗体把原有 X、Y、角度三个单值订阅改为一个“模板目标位姿列表”订阅。控件的新增、删除和布局修改全部放在对应 `.Designer.cs` 文件中，保证 WinForm 设计器可见。

界面显示：

- 基准目标：默认第 1 个；
- 基准中心、角度和尺度；
- 当前目标数量；
- 当前有效状态。

### 6.2 测量工具界面

- 编辑时只显示一个动态 ROI；
- 拖动过程中不创建、不显示其他目标的 ROI 副本；
- 点击“运行”时先识别当前 ROI 所属目标并标准化，再对所有目标测量；
- 运行完成后通过不可编辑的结果叠加层显示每个目标的测量效果、目标序号和数值；
- 再次进入绘制状态时清除运行叠加层，只保留唯一动态 ROI。

所有新增界面文字使用简体中文。若增加新控件，控件必须在 `.Designer.cs` 中声明、初始化和加入布局容器。

## 7. 运行数据流

```text
模板匹配
  → List<TemplateMatchPose>
  → 位置修正（第1个目标为基准）
  → MultiTargetPositionCorrectionResult.Items
  → 测量工具读取一套标准ROI
  → 对每个目标生成运行时ROI
  → 每个目标独立测量
  → List<目标测量结果>
  → 合并绘制结果并计算节点总体OK/NG
```

测量工具每轮只读取和转换一次输入图像。目标结果按索引预分配并按顺序写入，避免并发执行改变输出顺序。每个目标开始测量前检查取消令牌；单目标算法异常转换为该目标失败项，不中断其他目标测量。

## 8. 各测量工具的变换范围

- 卡尺找线：变换起点、终点和运行时卡尺方向；
- 卡尺找圆：变换圆心和角度范围；当前尺度为 1，不改变半径；
- 卡尺找椭圆：变换中心和角度；当前尺度为 1，不改变长短轴；
- 找点：变换全部搜索区域顶点；
- 线线角度：变换两条绘制线的端点；
- 点点距离：变换两个绘制点及其搜索区域；
- 点线距离：变换绘制点、绘制线及其搜索区域；
- 点区域距离：变换绘制点和区域全部顶点。

每个工具继续复用现有单目标算法；多目标层只负责为每个目标构造运行参数、调用算法、转换结果和合并显示，不复制算法实现。

## 9. 错误处理与节点状态

- 模板目标列表为空：位置修正和下游测量节点为 NG，并输出空结果列表；
- 未创建基准：位置修正节点失败，显示“请先创建位置修正基准”；
- ROI 无法确定所属目标：参数保存或预览运行被拒绝并显示简体中文提示；
- 单个目标测量失败或抛出异常：生成同序号失败项，数值写 `0`，继续测量后续目标；
- 全部目标成功：节点总体 `IsOk = true`；
- 任意目标失败或目标数量为 0：节点总体 `IsOk = false`；
- 停止令牌取消：停止后续目标，不把取消转换为普通测量失败。

日志按节点汇总输出目标总数、成功数、失败数和总耗时；仅在调试日志开启时输出逐目标详情，避免多目标场景产生高频 Info 日志。

## 10. 性能原则

- 单轮只取得一次上游 `OutputImage` 和灰度图；
- 标准 ROI 只解析一次；
- 变换服务不创建 Bitmap，不复制整幅图像；
- 多目标测量先采用确定顺序的循环，复用现有只读 Mat，避免无界并行和 OpenCV 内部线程争用；
- 绘制结果在全部目标完成后一次性合并并刷新界面；
- 结果集合按目标数量预分配容量。

## 11. 测试与验收

### 11.1 公共数据与变换

- 模板匹配三个结果时输出三个 `TemplateMatchPose`；
- 当前模型的每个位姿尺度均为 `1.0`；
- 尺度为 `0` 或负数时按 `1.0` 处理；
- 第一个目标正确创建基准；
- ROI 位于第二个目标时能自动识别并逆变换为标准 ROI；
- ROI 位于目标框外时选择最近目标；
- 旋转和平移变换及逆变换可往返还原。

### 11.2 八类测量工具

每类工具至少覆盖：

- 三个目标生成三个结果；
- 每个目标使用对应变换后的 ROI；
- 第二个目标测量失败时第二项数值为 `0`、总体为 NG，第一和第三项结果保留；
- 空目标列表输出空结果并为 NG；
- 取消令牌能够停止后续目标；
- 运行绘制结果包含全部目标序号和结果；
- 编辑状态始终只有一个动态 ROI。
