# 无监督训练界面设计

## 目标

在 `Forms/AiTrainForm/UnsupervisedTrainForm` 中先完成无监督训练界面和训练入口，不做流程识别节点。界面支持加载图像目录、按 All/OK/NG 查看缩略图、预览图像、可选绘制一个矩形 ROI，并把训练生成的无监督模板保存到运行目录 `Model` 文件夹。

## 范围

- 检查页：选择图像目录、递归加载图片、按 OK/NG 分类显示缩略图、右侧显示当前图像并支持一个矩形 ROI。
- 训练页：配置模型类型、阈值、最小面积、输入尺寸、训练轮数、批次大小、CPU/GPU/AUTO、模板名称和输出路径。
- ROI 规则：不画 ROI 时按整图训练；画 ROI 时只允许一个矩形 ROI，训练前写入模板。
- 环境隔离：运行环境只从 `AppDomain.CurrentDomain.BaseDirectory\UnsupervisedDll` 延迟加载；没有该目录时软件能正常启动，只有训练时提示环境缺失。
- 模板规则：训练产物打包成一个 `.tdunsup` 文件，内部包含 `manifest.json` 和 `model.onnx`，保存到运行目录 `Model` 文件夹。

## 非目标

- 本次不新增流程中的无监督识别节点。
- 本次不做多 ROI、多检测组、多模型分组。
- 本次不把无监督运行库复制进项目源码目录。

## 数据流

1. 用户在检查页选择图像目录。
2. 程序递归加载支持格式图片，并根据路径或文件名中的 OK/NG/正常/异常等标记分类。
3. 用户可筛选 All/OK/NG，点击缩略图后在右侧预览。
4. 用户可不画 ROI，或在预览图上画一个矩形 ROI。
5. 训练页读取当前图像集合、ROI 和训练参数，生成临时训练数据集。
6. 程序延迟初始化 `UnsupervisedDll\AnomalibLib.dll`，调用训练接口。
7. 训练成功后查找最新 ONNX，连同 ROI 和参数写入 `.tdunsup` 模板文件。

## 错误处理

- 图像目录不存在、没有图片、没有 OK 图片时阻止训练并提示。
- ROI 多于一个、ROI 越界或面积为 0 时阻止训练并提示。
- `UnsupervisedDll` 缺少 `AnomalibLib.dll` 或许可证时阻止训练，但不影响窗体打开。
- 模板输出路径不在运行目录 `Model` 下时阻止选择。
- 训练异常写入界面日志和软件日志。

## 验证
