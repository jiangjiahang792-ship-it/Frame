# 无监督节点保存时预加载设计

## 目标

无监督参数窗体点击“保存”后，在后台完成模板解包、native 模型加载和空图预热。只有全部成功后才提交新参数并关闭窗体，使流程首次运行直接进入推理。

## 方案

- 模板选择和刷新只读取 `.tdunsup` 中的 `manifest.json`，不再解包 `model.onnx` 到预览目录。
- 无监督节点增加独立的运行配置门，预加载、参数提交与流程推理共用同一把锁，防止出现新模型搭配旧参数的情况。
- 运行时先创建候选检测器，完成加载和空图预热后再原子替换当前检测器；任何失败都释放候选检测器并保留旧检测器。
- 保存期间禁用模板选择、刷新和保存按钮，并显示“模型加载中...”；失败时窗体保持打开并显示简体中文原因。
- 旧方案未重新打开参数窗体保存时，运行时仍保留首次调用 `Infer` 时加载模型的兼容路径。

## 验证

- 结构测试检查轻量清单读取、异步保存、预加载入口、空图预热和候选模型原子替换。
- 行为测试动态编译生产配置门，验证并发推理不会越过未完成的模型提交，并验证加载失败不提交新参数。
- 运行无监督既有专项测试，并分别编译 `Debug|x64` 和 `Release|x64`。
