# ROI结果绘制两类型简化设计

日期：2026-07-22

## 1. 目标

将“ROI结果绘制2”的绘制项由“文本、线、矩形、区域/轮廓”简化为“文本、ROI”两种用户可见类型。用户只负责选择内容类别和订阅来源，程序根据订阅值的实际类型自动识别并绘制几何结果。

本次同时把颜色判定由节点内部的多条规则组合简化为单个布尔订阅。复杂条件由上游“多条件”节点汇总，ROI结果绘制节点只负责显示。

## 2. 非目标

- 不删除旧方案中已经保存的线、矩形、区域枚举值和多条颜色规则数据。
- 不把文本自动混入ROI项；文本必须使用独立文本项。
- 不改变图像显示控件使用 `AlgorithmResult` 绘制叠加层的总体方式。
- 不为每一种新几何类型继续增加窗体按钮或下拉选项。

## 3. 界面设计

### 3.1 基础设置

参数窗体顶部保留以下设置：

- 输入图像订阅，输入契约只接受图像。
- 可选的颜色判定订阅，输入契约只接受单个布尔值。
- OK颜色和NG颜色。

删除颜色规则表、规则添加与删除按钮、“全部为真/任一为真”下拉框以及多条件项选择。多条件判断必须在上游多条件节点完成，并输出最终布尔值。

### 3.2 绘制项列表

绘制项操作只保留：

- 添加文本。
- 添加ROI。
- 删除。

列表显示启用状态、类型和内容摘要。删除用户可编辑的名称输入框，名称由项目类型与订阅来源自动生成。旧方案中的线、矩形、区域项目统一显示为“ROI（旧配置）”。

### 3.3 文本设置

文本项显示：

- 启用状态。
- 手动文本或订阅文本二选一。
- 手动内容或订阅来源。
- 订阅文本前缀。
- 字号和显示位置。

坐标系、边距和未找到提示样式放入可折叠的高级设置，默认收起。

### 3.4 ROI设置

ROI项显示：

- 启用状态。
- ROI订阅来源。
- 线宽。

ROI订阅列表只显示可由几何适配器处理的类型。用户不再选择线、圆、矩形或区域等具体类型。

### 3.5 预览

保留预览区域、“预览”和“保存”按钮。参数变化后由用户点击预览，不在每次控件变化时自动运行算法，避免高频重复计算。

## 4. 数据模型与旧方案兼容

### 4.1 绘制项类型

`ResultOverlayDraw2ItemType` 新增 `Roi`。已有 `Text`、`Line`、`Rectangle`、`Region` 枚举值必须保留，以保证使用字符串枚举序列化的旧 `.Sol` 文件仍能反序列化。

新添加的ROI项使用 `Roi`。旧类型在界面显示为“ROI（旧配置）”，运行时继续执行原先的专用绘制语义，不因软件升级而突然绘制更多几何内容。

### 4.2 单个颜色判定

`NodeParamResultOverlayDraw2` 新增单个颜色判定订阅的节点文本和结果文本。新节点不再创建颜色规则集合。

旧 `ColorRules` 和 `RuleMode` 属性继续保留并参与反序列化：

1. 新单个布尔订阅存在时，以新订阅为准并忽略旧规则。
2. 新订阅为空且旧规则存在时，继续执行旧规则聚合逻辑。
3. 参数窗体显示“当前使用旧版颜色规则”提示。
4. 用户选择新的布尔判定后，保存时清空旧规则。
5. 用户没有选择新判定时，保存必须保留旧规则，不能静默改变旧方案行为。

### 4.3 旧字段保留

绘制项的 `Name`、旧类型和样式字段继续保留，避免旧方案数据丢失。新界面不再要求用户维护名称，但保存时根据类型和订阅来源生成稳定的显示名称。

## 5. ROI自动适配架构

### 5.1 接口

新增 `IOverlayGeometryAdapter`，职责仅包括判断能否处理订阅值以及把几何内容追加到目标 `AlgorithmResult`。窗体不依赖具体几何类型，构建器不再通过用户选择的几何类型决定新ROI项的分支。

新增 `OverlayGeometryAdapterRegistry` 统一管理适配器顺序、支持的数据类别及运行时分派。后续增加新的ROI类型时，只注册新适配器，不修改参数窗体。

### 5.2 内置适配器

- `AlgorithmResult`适配器：复制矩形、线、圆、圆弧、椭圆和轮廓，不复制文本。
- 测量结果适配器：从测量结果或其公开 `AlgorithmResult` 中提取几何显示结果。
- 基础几何适配器：处理单个点、线、圆、椭圆、矩形和旋转矩形。
- 集合适配器：处理点集、轮廓、区域、普通集合和多目标集合，并递归交给适配器注册表。

直接点结果绘制为十字标记；点集合按点集合类别绘制多个十字，轮廓和区域按折线/闭合轮廓绘制，不能仅凭 `IEnumerable<PointF>` 猜测业务含义。

### 5.3 类型契约

ROI订阅输入契约接受以下统一订阅类别：

- 点、点集合。
- 线、圆、椭圆、矩形。
- 轮廓、区域。
- 测量结果、算法结果。

集合和多目标数量由输出描述符的复数信息表达。类型不受来源节点名称限制。

### 5.4 性能

- 每个绘制项每次运行只读取一次订阅值。
- 类型到适配器的解析结果按运行时类型缓存。
- `AlgorithmResult` 直接复制强类型集合，不对每个元素重复反射。
- 测量结果属性提取器按类型缓存。
- 参数窗体只刷新订阅目录，不在编辑事件中执行绘制算法。

## 6. 颜色规则

配置新布尔判定时：

- `true` 使用OK颜色。
- `false` 使用NG颜色。
- 文本和ROI统一使用该状态颜色。

没有配置新布尔判定且没有旧规则时：

- 上游几何或文本自带颜色时保留原颜色。
- 上游元素没有有效颜色时使用OK颜色作为默认颜色。
- 手动文本使用OK颜色。

新布尔判定存在时，状态颜色覆盖全部新ROI项的上游颜色。旧配置仍按旧实现的颜色保留规则运行，防止旧方案显示变化。

## 7. 运行数据流

1. 读取输入图像。
2. 解析单个布尔颜色判定；不存在时检查旧规则；两者都不存在时进入保留来源颜色模式。
3. 依次遍历启用的绘制项。
4. 文本项只生成文本。
5. 新ROI项读取一次订阅值并交给几何适配器注册表。
6. 旧线、矩形和区域项继续调用旧专用逻辑。
7. 输出克隆后的图像和统一 `AlgorithmResult` 显示层。

## 8. 异常与空结果

- 新建ROI项未选择订阅时，保存前给出简体中文提示。
- 订阅属性不存在时，提示包含绘制项序号、来源节点和结果名称。
- 运行值类型无法由任何适配器处理时，节点判定为NG并记录实际类型。
- 测量节点未找到目标时继续生成红色“未找到”提示。
- AI、无监督和大模型节点成功运行但没有缺陷几何时属于有效空结果，不生成“未找到”。
- 布尔判定无法读取时节点判定为NG，错误信息包含订阅来源和实际类型。

## 9. 验证

自动检查至少覆盖：

- 界面只提供添加文本、添加ROI和删除按钮。
- Designer文件包含全部新增或调整的WinForms控件及事件绑定。
- ROI订阅契约不展示布尔、数值、文本和图像。
- 混合 `AlgorithmResult` 一次复制全部几何但不复制文本。
- 单个几何、点、点集合、轮廓和多目标集合。
- 新布尔判定的OK/NG颜色覆盖。
- 无判定时保留来源颜色以及默认颜色回退。
- AI成功空结果和测量失败结果的不同处理。
- 旧绘制类型和旧颜色规则兼容。
- 方案序列化往返。
- `Debug|x64` 完整编译。
