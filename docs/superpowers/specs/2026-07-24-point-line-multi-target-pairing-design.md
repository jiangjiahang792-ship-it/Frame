# 点到线距离多目标订阅配对设计

## 目标

点到线距离节点既支持两个多目标来源按 `TargetIndex` 一一配对，也支持一个公共单结果与另一侧全部目标组合。

## 数据规则

- 多目标身份只认 `TargetIndex`，不依赖集合下标或算法完成顺序。
- 点与线的目标编号相同才组成一组，例如点2只能与线2计算。
- 一侧只有一个成功结果、另一侧存在多个目标时，将这个单结果广播到另一侧全部目标；例如8个点和1条公共直线输出8个距离。
- 广播后的结果目标编号采用多目标一侧的 `TargetIndex`，但继续携带单结果原始几何值。
- 任一侧目标失败、缺失或无法读取几何值时，保留该目标结果，所有数值为 `0`，该项为 NG。
- 全部目标均成功时节点总体为 OK；任一目标失败时节点总体为 NG。
- 订阅来源没有多目标明细时继续按旧方式读取一个摘要结果，保证旧方案兼容。
- 多目标执行保持串行，不引入任务并发和额外图像复制。

## 结构

新增通用的目标编号配对组件，输入为两组带 `TargetIndex`、状态和值的数据，输出按目标编号排序的配对结果。点到线距离窗体负责把上游点、线结果转换为通用输入，并复用现有距离算法和结果汇总。通用结果读取器增加从单个多目标结果项读取点或直线的能力。

## 校验

- 三个点与三条线编号相同，输出三个正确配对。
- 八个点与一条成功公共线，输出八个成功配对；一个点与八条线规则对称。
- 中间目标失败时仍输出三个结果，目标2为 `0/NG`，目标3不前移。
- 双方数量都大于一且目标编号集合不一致时，缺失编号保留为 `0/NG`。
- 唯一单结果自身为NG时不广播为成功，所有组合目标保持NG。
- 单结果订阅继续输出一个结果。
