# TDJS-Vision 客户介绍演示文稿设计说明

## 1. 制作目标

制作一份面向企业管理层与自动化、视觉工程师的中文客户介绍演示文稿，全面说明 TDJS-Vision 工业视觉应用框架的软件定位、基本功能、设备与相机接入、流程搭建、视觉算法、通信能力、结果追溯和典型应用。

演示文稿以项目当前代码、`README.md`、`ToolTreeView.xml`、主窗体、设备实现和节点实现为事实依据，不把规划功能描述为已经交付的功能。

## 2. 受众与表达策略

- 管理层关注：平台能解决的质量问题、项目交付效率、复用价值、扩展能力和应用范围。
- 技术人员关注：方案—流程—节点架构、相机与设备接入、算法节点、通信协议、流程控制和数据输出。
- 采用双层表达：每个技术章节先给出客户价值，再补充实现能力和典型使用方式。
- 所有界面文字和演示文稿正文使用简体中文。

## 3. 推荐叙事路线

采用“业务价值—平台能力—技术架构—应用场景—项目落地”的综合叙事路线。

1. 说明工业视觉项目的常见难点。
2. 给出 TDJS-Vision 的平台定位与总体价值。
3. 展示软件界面、方案—流程—节点架构和完整检测闭环。
4. 依次介绍相机、光源、通信、图像处理、传统视觉、测量、AI 与流程控制。
5. 汇总可实现的视觉应用与行业场景。
6. 以平台化交付流程和合作价值收束。

## 5. 已确认的软件能力边界

### 5.1 软件框架

- 基于 .NET Framework 4.8 和 WinForms。
- 采用“方案—流程—节点”编排模型。
- 方案支持保存、加载、另存、单次运行、循环运行和停止。
- 流程支持分组、优先级、主动与被动触发、并行分支、条件控制和运行统计。

### 5.2 图像与相机

- 2D 图像源、3D 图像源、2D 图像显示和 3D 图像显示。
- 2D 相机代码覆盖海康、Basler、华睿和大华设备识别逻辑，具体兼容范围以现场 SDK、型号和联调结果为准。
- 3D 相机当前实现以海康 3D 线激光轮廓相机为主，支持深度、强度、原始数据和点云相关数据。
- 支持连续采集、软触发和线路硬触发等配置方式。

### 5.3 设备通信

- 光源控制。
- PLC 读写，代码中包含三菱与松下实现。
- Modbus RTU/TCP 主从站相关能力。
- TCP Client/Server。
- 串口发送。
- 相机 I/O、软触发监听、全局信号和科锐 I/O 模块节点。

### 5.4 视觉与测量

- 图像裁剪、旋转、分割和综合预处理。
- 直线、圆、二维码、模板、颜色、二值化分析和电池极耳检测。
- 卡尺找线、卡尺找圆、卡尺找椭圆、找点和位置修正。
- 点点距离、点线距离、点区域距离、线线夹角和线组合拟合。
- AI 检测支持 DET、OBB、SEG、POSE 类型。
- 已有无监督检测与大模型调用节点。

### 5.5 流程与结果

- 共享变量、条件运行、If/Else/EndIf、多条件判断、四则运算、流程触发、流程信号和等待流程完成。
- 支持组合模块、组合输入、组合输出和 C# 脚本扩展。
- 支持结果绘制、结果汇总、检测结果显示、图片保存、定期删除图片和 Excel 导出。

## 6. 典型应用范围

- 尺寸测量：长度、间距、角度、圆径、椭圆、位置偏差和轮廓相关测量。
- 外观缺陷：划伤、脏污、破损、缺料、异物、毛刺、压伤和表面异常。
- 装配检测：漏装、错装、反装、偏位、间隙和装配完整性。
- 定位引导：模板定位、特征定位、位置修正和机器人或运动机构坐标输出。
- 识别追溯：二维码、颜色、类别、批次、图片、结果表格和检测统计。
- AI 应用：目标检测、实例分割、姿态关键点、旋转目标检测、少样本或无监督异常检测，以及受控的大模型辅助分析。
- 3D 应用：高度差、轮廓、平面度、台阶、缺口和体积类应用方向；具体测量精度取决于相机、标定、光学与现场条件。

## 7. 视觉设计

- 使用项目现有 Logo 和绿色工业科技风作为主视觉。
- 采用深绿色、青绿色、白色和深灰色配色，避免过度装饰。
- 以真实软件界面截图为核心证据，辅以简洁的流程图、能力矩阵和应用场景图。
- 标题不少于 35 磅，正文不少于 16 磅；优先减少文字，不通过缩小字号解决拥挤。
- 单页只表达一个主要结论，管理层能快速读懂，技术人员可以从注释和能力列表获得细节。

## 8. 素材与真实性原则

- 优先使用实际运行的软件主界面、流程画布、相机管理、通信管理和结果界面截图。
- 若本机无法运行软件或缺少设备，使用设计器界面、代码结构和抽象示意图替代，并明确标注为能力示意。
- 不展示客户名称、生产数据、设备序列号、IP 地址、账号或其他敏感信息。
- 不声明未经代码或现场验证的精度、节拍、兼容型号数量和投资回报率。

## 9. 验收标准

- 内容完整覆盖用户要求的基本功能、通信设备、相机、流程搭建和视觉应用。
- 管理层可以理解平台价值，工程师可以理解实现路径和扩展方式。
- 每项核心能力与当前项目文件一致，不夸大兼容性或性能指标。
- 演示文稿全部使用简体中文。
- 每一页完成渲染检查，无文字截断、异常换行、越界或非预期重叠。
