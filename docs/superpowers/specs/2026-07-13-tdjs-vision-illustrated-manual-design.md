# TDJS-Vision 图文增强版功能说明书设计

## 1. 目标

在现有《TDJS-Vision 工业视觉应用框架功能与应用说明书》的基础上，运行 `bin/x64/Release/机器视觉AI检测系统V1.0.exe`，逐项查看实际软件界面，为客户形成一份“界面截图、入口位置、参数说明、操作步骤、算法逻辑和应用组合”相互对应的图文增强版 Word 说明书。

## 2. 交付方式

- 保留现有纯说明版，不覆盖原文件。
- 新增图文增强版：`outputs/TDJS-Vision工业视觉应用框架功能与应用说明书-图文增强版.docx`。
- 截图原图保存在 `docs/manual-assets/screenshots/`，便于后续替换、补拍和复用。
- 所有截图采用简体中文图题，并使用编号、箭头或文字标签说明入口、参数区、结果区和操作顺序。

## 3. 截图范围

### 3.1 平台基础

- 登录与权限界面。
- 主界面整体布局。
- 方案管理、流程管理和流程画布。
- 工具箱、参数区、图像区、结果区和日志区。
- 运行控制、系统设置、全局信号与检测项配置。

### 3.2 设备与通信

- 二维相机、光源、PLC、Modbus、TCP、串口等设备配置入口和参数界面。
- 依赖现场硬件的功能，在离线状态下优先截取可打开的配置窗口，并注明连接前提。
- 不伪造在线连接、采集成功或通信成功状态。

### 3.3 流程节点

- 覆盖工具箱中的图像采集、图像处理、检测识别、测量工具、图形创建、设备通信、逻辑工具和结果处理节点。
- 参数窗口可以正常打开的节点，至少保留一张完整参数界面截图。
- 同类且界面高度相近的节点可共用分类总览图，但每个模块仍分别给出入口、关键参数、输入输出和使用步骤。
- 需要上游图像、ROI、模型、设备或流程结果才能完整显示的节点，应说明前置条件和离线演示限制。

### 3.4 三维功能边界

- 只介绍当前已有的三维相机连接、`3D图像源`和`3D图像显示`。
- 只说明三维数据采集、显示入口和基本参数。
- 明确注明当前版本主要完成三维数据采集，三维测量、点云处理和缺陷检测算法尚未集成。
- 不扩写尚未实现的高度、平面度、体积、焊缝等三维算法能力。

## 4. 单模块图文结构

每个模块按以下结构组织：

1. 模块名称与所在工具箱分类。
2. 实际软件入口截图或工具箱定位截图。
3. 参数窗口截图，使用编号标出关键区域。
4. 使用前提：所需图像、ROI、模型、设备、变量或上游结果。
5. 操作步骤：添加节点、连接输入、设置参数、单步运行、核对输出、连接下游。
6. 关键参数：参数含义、建议调试顺序和常见范围选择原则。
7. 输入与输出：说明数据类型、坐标或状态如何传递。
8. 基本算法逻辑：用客户可理解的语言解释处理原理。
9. 推荐组合：给出常用上下游节点和典型应用。
10. 使用注意：列出节拍、稳定性、硬件依赖和边界样本风险。

## 5. 截图与标注原则

- 软件必须从指定 Release 目录启动，截图内容以实际运行界面为准。
- 截图优先使用完整窗口或完整参数面板，避免只保留无法判断上下文的局部区域。
- 涉及账号、路径、设备序列号、IP、产品数据等敏感或现场专用内容时进行遮挡或避免纳入截图。
- 标注不覆盖控件文字；编号与说明保持统一配色和位置。
- 相同界面不重复堆放，必要时通过“入口总览图 + 模块参数图”组合说明。
- 对无法在无硬件环境下完成的动作，如相机采图、PLC读写和光源响应，明确标注“需连接设备验证”。

## 6. 文档结构调整

- 保留原说明书的封面、导航、框架概述、快速上手、模块说明、典型应用、调试建议和附录。
- 在平台基础章节增加主界面与工作流程截图。
- 在每个模块说明中插入图题、截图和图中编号说明。
- 在典型应用章节增加流程搭建示例截图；无法建立完整现场流程时，使用离线节点组合演示，不伪造检测结果。
- 附录继续保留完整模块索引，并增加截图编号或图文页定位。

## 7. 验收标准

- 指定 Release 程序能够启动并完成界面遍历。
- 二维视觉、通信、逻辑和结果处理模块均有实际界面依据。
- 每个模块都有明确的使用步骤、关键参数、输入输出和算法逻辑。
- 三维内容严格限制为取图和显示，不宣称未实现的算法。
- 图文增强版与纯说明版分开保存。
- Word 文档使用标题样式、图题、页眉页脚和统一截图宽度。
- 最终 DOCX 完成全页渲染检查，不存在图片越界、文字过小、图题分离、表格截断或空白异常页。

## 8. 风险与处理

- 软件可能需要授权、登录、模型、方案或硬件：优先记录可访问界面，并对受限功能注明前提，不绕过授权或安全机制。
- 部分节点可能只有加入流程后才能打开参数：建立专用离线演示方案，按分类逐个添加节点并截取参数窗口。
- 节点数量多导致文档过长：保留每个模块的独立说明，但合并重复的分类总览图和公共操作步骤。
- GUI 自动操作可能受弹窗或窗口焦点影响：每次操作后校验窗口标题和截图内容，避免截错界面。
