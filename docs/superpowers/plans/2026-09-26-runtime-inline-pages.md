# 运行界面内联页签实施计划

**目标：** 按已观察到的 VM 页签右侧加号交互，在设计器直接新增和切换运行界面，取消单独管理窗口。

**架构：** 沿用 RuntimeInterfacePage、方案保存事务和独立运行窗体宿主。设计器为每页持有独立编辑会话，通过 CreateForPages 工厂接入多页保存，旧单页构造方法保持兼容。

**技术：** C# 7.3 / .NET Framework 4.8 / WinForms。

## 实施范围
- [x] 编辑器增加暗色页签、橙色选中状态及标签右侧加号，固定控件放入 Designer 文件。
- [x] 每页独立布局、绑定、撤销；切换不丢草稿；统一保存和退出保护。
- [x] 主窗体直接打开多页设计器，移除管理窗口入口和无用实现。
- [x] 更新纯内存体验程序，保留多个独立模拟运行窗体。
- [x] 验证新增、切换、撤销隔离、保存取消与失败、旧方案迁移、ROI 和运行宿主回归。

## 约束
- 不修改任何现场方案或 PLC 通信，不启动生产主程序。
- 多页编辑标签不改变运行时“一页一个独立窗体”的语义。
- 不另加参数设置或管理对话框；页面名称沿用既有页面属性。
- 验证后只交付当前工作区，不提交或合并分支。
