# ROI 订阅与多运行窗体

## 范围

- 图像控件分别绑定图像输出与 ROI 输出，沿用完整流程/组合模块/节点路径。ROI 只读订阅，复用框架绘制契约，不执行节点，不改变生产图像。
- 方案持有可增删、命名的运行界面集合；每项有稳定标识和独立布局。两个配置对应两个独立运行窗体，不做成同一窗体的标签页。
- 原单界面方案加载时迁移成集合中的一项；没有布局的旧方案保持空集合。模板导入导出仍针对一个布局，不改原有模板语义。
- 管理窗体维护编辑副本，保存走原方案安全保存入口；取消不修改方案。编辑器保存先回到管理草稿，管理窗口统一提示并保存。
- 各运行窗体共享框架执行入口，保持注销权限、方案作用域和全局停止语义。关闭一个窗体仅释放它的订阅，不能关闭其它运行窗体或停止生产。

## 实施与验证

1. 增加多界面序列化、旧格式迁移、无效标识与隔离副本测试。
2. 增加界面集合模型及管理窗体，固定控件位于 Designer 文件；接入方案保存/加载/重置。
3. 主窗口改为按界面标识管理独立窗口，测试两个窗口、重复打开、关闭单个、旧窗口失效。
4. ROI 后端与选择界面分工实施，覆盖独立更新、失效清除、坐标缩放及资源释放。
5. 编译独立输出目录；运行相关回归与无设备 UI 验证，不启动生产主程序，不修改现场 `.Sol`。
