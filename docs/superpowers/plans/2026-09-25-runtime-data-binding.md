# 运行界面图像与耗时绑定实施计划

## 目标与范围

按用户已确认的下一步，先完成图像显示和流程/节点耗时的真实数据绑定。实际检查 VM 后采用右侧数据源只读路径、省略号选择、清除按钮，以及流程/组合模块/节点/输出树。文本和信号灯暂保留示例配置。沿用当前增加界面设计器分支；按用户要求直接实现，不重复请求批准，不自动提交既有工作。

## 设计

- 可序列化绑定保存根流程 ID、逐级组合模块/节点 ID 路径、输出属性路径及显示名称；名称不参与解析。复制、撤销和导入导出隔离绑定副本，旧模板缺省为空。
- 选择器复用 SubscriptionPortCatalog，只列出图像类型可用输出；耗时提供流程和节点运行耗时。组合模块可展开其内部节点；运行期间只访问已创建内部流程，不初始化、不执行节点。
- IRuntimeBindingCatalog 提供树目录；运行数据源只订阅现有流程完成通知，避免部分节点先发布成功状态、后替换结果导致读到旧帧。图像事件取得既有资源租约，后台转换 Bitmap；每个绑定只保留最新待显示结果，定时合并刷新，不做 PLC 通信，不修改执行调度。
- 运行值与布局文档分离，不把每帧图片编码进模板。未运行显示等待状态，缺失绑定显示失效状态，不擅自按同名节点重绑。
- 主窗口新增自定义运行界面入口，独立非模态显示，关闭返回默认运行界面；不替换旧流程和图像窗口。切换方案后停止旧视图订阅，避免显示上一方案数据。

## 验证结果（2026-09-26）

- Release x64 输出 `bin/x64/DesignerBindingVerify`，编译成功；绑定 75 项、选择器 65 项、原设计器 104 项、窗口外观 281 项断言通过。
- 性能专项通过：无图片三控件模板移动并绘制 P95 7.44 ms，缩放并绘制 P95 8.07 ms；不将此数字解释为现场多相机性能。
- 资源测试覆盖 40 帧替换、图像租约释放、关闭期间迟到帧释放；确定性屏障覆盖模块重建与提取交错，另覆盖重建首轮失败以及后续槽位解析异常不影响已转换图像。
- 已检查 VM 实际绑定操作及本地真实窗口；独立体验程序的模拟来源不连接设备，未覆盖现场生产方案联调。

## 风险检查

组合模块重建后不读取旧实例；同名与重复节点 ID 按完整作用域区分；图像释放竞态由租约处理；高频更新不积压 UI 任务；方案切换和窗口关闭都释放待显示及已显示图像。耗时沿用框架现有 RunTime 口径，不新造计时含义。图像本轮先显示选定 OutputImage 的首张图，ROI 叠加配置不在本轮范围。
