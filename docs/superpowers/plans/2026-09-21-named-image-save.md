# 命名存图实现计划

> 执行方式：当前任务内按步骤实现并验证，复用已有存图工作池。用户要求直接修改并记录任务，不额外等待批准。

**目标：** 新增“命名存图”节点，盘符加单列列表自上而下组成多级目录，每行可手填或订阅结果，最后一级保存图像。

**设计依据：** 用户已确认多行表示目录层级；文件名暂按独立手填/订阅、留空时间戳实现。保留原保存图片节点。

**结构：** NamedImageSave目录中分离配置、订阅读取与路径计算、运行入队、WinForms参数及设计器。采用NodeFactory、稳定节点ID和统一订阅目录；沿用ImageQueueProcessor的图像租约、后台编码和原子重名保护。

**约束：** 简体中文控件和注释；控件在.Designer.cs；后台运行读取保存的参数，不依赖UI选择；新增枚举项只追加；路径中的动态值不能突破所选盘符；异常命名记录日志并回退，设备失败/失效订阅明确报错。

## 实现与验证

- [x] 配置与路径：定义源节点ID/属性路径、目录行、文件名和图像源。一次读取上游映射，按顺序拼接，每个动态组件只允许一个目录名，数值按不变区域转换，布尔保留True/False。验证混合文字/PLC/共享变量/多条件、改名和参数JSON往返、空和非法名称。
- [x] 节点与注册：追加NamedImageSave枚举、两处工厂、工具箱XML、显示名及颜色；实现订阅依赖、快照入队、取消与释放。验证队列拒绝不能伪报成功、PNG/JPEG图像资源正确释放及同名不覆盖（沿用JPEG保存）。
- [x] 参数界面：顶部盘符、左侧单列目录、增加/删除/插入/上下移动、当前行手填编辑、右侧统一结果树及订阅按钮、图像选择、独立文件名、JPEG质量、路径预览。配置初始一行，列表变更立即反映编辑草稿，保存时验证并复制，重开/切换行不串订阅。
- [x] 实际验证：真实NodeFactory创建、真实PLC/共享变量/多条件输出目录、后台写盘可解码、动态变化和重名、非法字符日志、参数窗体按钮及截图。构建独立Release目录后回归现有存图、订阅及构建常用Release目录，记录结果。

## 重点边界

- 保存后方案重新加载仍按稳定节点ID读取，来源改名不破坏配置。
- 删除/断开/禁用或本轮失败的源不能沿用旧数据。
- 当前行编辑后直接增加/插入/切换行/保存，不丢失编辑内容。
- 非法文件夹/保留名/路径穿越值不能逃离盘符；以备用目录保存并带行号记日志。
- 图像入队后原结果释放，后台仍可保存；节点释放与入队竞争不会遗留租约。
