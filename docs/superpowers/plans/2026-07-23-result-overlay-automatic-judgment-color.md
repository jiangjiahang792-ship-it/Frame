# ROI结果绘制自动判定颜色实施计划

> **执行约束：** 当前任务内直接实施，不创建分支、不提交 Git；按测试先行完成修改。

**目标：** 删除ROI结果绘制中的独立“颜色判定”订阅，改为从每个绘制项的来源结果自动读取OK/NG状态。

**实现方式：** 新版文本和ROI绘制项优先读取来源节点结果的 `IJudgmentResult.JudgeOk`，兼容读取 `IsAllOk`、`IsOk`、`ConditionResult` 等布尔状态；没有任何判定状态时默认OK。OK/NG颜色仍由节点参数统一配置，旧方案的逐项颜色字段和旧绘制类型继续兼容运行。

**技术环境：** C#、.NET Framework、WinForms、PowerShell回归检查、MSBuild。
