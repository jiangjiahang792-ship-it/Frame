# 运行界面设计器第一阶段

## 已确认范围

方案关联界面配置，支持独立模板导入导出。采用 VM 式深色画布、浅色工具箱和属性栏，提供图像显示、运行耗时、文本框、信号灯四种组件。当前阶段验证布局和预览效果，不连接生产设备，不自动执行流程。

## 实施结构

- `Forms/RuntimeDesigner/RuntimeLayoutDocument.cs`：版本化布局和组件属性。
- `Forms/RuntimeDesigner/RuntimeLayoutSerializer.cs`：受限 JSON 读写、校验、嵌入图片和原子保存。
- `Forms/RuntimeDesigner/RuntimeLayoutSession.cs`：工作副本、添加、复制、边界约束、撤销重做。
- `Forms/RuntimeDesigner/RuntimeWidgetRenderer.cs`：可注册的四种绘制组件和图片资源生命周期。
- `Forms/RuntimeDesigner/RuntimeDesignCanvas.cs`：坐标缩放、网格、拖入、移动、八方向缩放、选择和预览。
- `Forms/RuntimeDesigner/RuntimeInterfaceEditorForm.cs` 与 `.Designer.cs`：设计器布局、属性编辑、文件操作和保存回调。
- `ConfigHelper.cs`、`Solution.cs`：可选的 `RuntimeInterface` 字段随方案保存、加载和重置；旧方案缺少字段时保持兼容。
- `FormMain.cs` 与 `.Designer.cs`：视图菜单入口。
- `Tests/RuntimeInterfaceDesigner.Tests.cs` 与 `.ps1`：行为测试和独立预览启动器，不初始化硬件。

## 实施顺序

1. 编写模板保存加载、非法模板拒绝、工作副本隔离、撤销重做、移动缩放边界的测试，确认缺少功能时失败。
2. 实现布局文档、保存服务和编辑会话。
3. 实现四类渲染器和画布交互，再实现可在 WinForms 设计器中查看的编辑器窗体。
4. 接入方案字段与菜单；编辑器保存成功前不修改当前方案，关闭未保存编辑时提示。
5. Release x64 编译、专项行为测试、原有方案保存测试、实际桌面拖拽和预览检查。

## 验收重点

- 导入失败不破坏当前布局；未知版本、未知类型、超大文件、重复 ID 和越界尺寸拒绝。
- 图片随模板携带，原图片删除后仍可显示；编辑和关闭正确释放 GDI 资源。
- 缩放后移动和改变尺寸使用设计坐标，组件不能拖出画布。
- 属性输入非法数值能够恢复；删除后撤销恢复原组件及其顺序。
- 初始空白画布，控件真实拖入；预览明确使用示例数据，不产生 PLC、相机、流程调用。
