# 飞丝位置学习记录

## 样图结论

本次样图和用户红框标注表明，飞丝位置具有一致的相对关系：

1. **主检测区域**：编织屏蔽层上方的半透明绝缘层下端，靠近绝缘层与编织层的交界处。
2. **红框所在位置**：红框位于绝缘层的下半段，通常贴近右侧或中部表面，并不以编织层本体作为主要检测区域。
3. **形态特征**：飞丝表现为绝缘层表面或边缘的一根细黑线，可能近似竖直、向外弯曲或呈短弧形；长度方向大致沿产品轴向。
4. **不属于飞丝的区域**：金属压接环本体、黑色外护套、编织层密集纹理、绝缘层上部正常纹理、背景边缘和高亮反光。

## 建议的定位口径

后续检测应先定位产品中心轴，再取“半透明绝缘层下端至编织层上沿”的窄带区域作为飞丝候选 ROI。ROI 的下边界贴近绝缘层与编织层交界线，上边界向绝缘层上方保留少量余量，横向覆盖绝缘层宽度并保留两侧少量余量；编织层主体和金属环不作为主要检测区域。

飞丝计数应按独立连通的细丝目标统计，同一根与编织层相连的丝只计一次。金属环边缘、编织纹理和反光形成的短粗块状区域不应直接计为飞丝。

## 与现有模型解析的对应关系

- AI 模型：继续使用飞丝类别的检测框数量作为“飞丝”检测项。
- 传统算法：优先在上述绝缘层下端窄带 ROI 内做暗线/边缘候选提取，再用长度、宽度、细长比、轴向方向和与交界线的距离过滤。
- 结果判定：飞丝检测项仍按数量型检测项处理，默认 `0～0`；数量大于零时判定 NG。
