# AST工位1分割模型

目标检测节点模型名称选择“AST工位1分割模型”，与原“AST-工位1模型”DET解析独立。

## 配置

- 导入 `Template/TDAI/AST工位1分割模型.ai`；对应的可读配置为 `AST工位1分割模型配置.json`。
- 检测项管理导入 `Template/TDAI/AST工位1分割检测项.items`，在节点选择该检测项集合。
- 默认CPU、SEG、640，置信度0.25，NMS 0.45。配置指向 `D:\MyCode\PublicWook\Fakra_SEG模型测试\FAKRA（AST-CCD1）-SEG20260923\model.onnx`，其它电脑需要重新指定模型路径。
- `.ai`是软件既有加密格式的配置文件，不代表ONNX模型已加密。当前模型为未加密ONNX。
- 示例公差1～99999只用于接入测试，不是生产合格公差，投产前应设置或学习实际公差。

标签顺序必须是：

| ID | 训练标签 | 对应部件 |
| --- | --- | --- |
| 0 | insulation_glue | 绝缘胶 |
| 1 | shielding_mesh | 屏蔽网 |
| 2 | copper_ring | 铜环 |
| 3 | rubber | 胶皮 |
| 4 | fly_line | 飞丝 |

## 测量

模板默认仅启用SEG测试程序的两项距离：

1. 绝缘胶顶部最低点到屏蔽网顶部最低点的距离：中央60%有效宽度逐列取首个前景像素，再取最大Y，两侧各排除20%。

“L2_编组切割长度”（旧名“屏蔽网高度”）使用同样的顶部最低点规则，计算胶皮与屏蔽网的 `UpperEdgeLowestY` 差绝对值，不再取屏蔽网自身掩膜高度。两个部件各取最高置信度有效实例；重叠时仍计算该差值，缺少部件或有效取点时显示0并判NG。测量箭头跟随这两个取点，比例换算及原有上下限保持不变。该变更仅适用于工位1SEG解析。
2. 绝缘胶顶部到铜环底部的距离：绝缘胶最小有效Y到铜环最后有效Y。

同类多个实例的尺寸、距离使用最高置信度实例；飞丝数量使用全部有效实例。也支持原工位1的胶皮间距、绝缘胶/屏蔽网/铜环宽高以及胶皮宽高。宽高取有效掩膜包围范围，不取模型矩形；胶皮间距取相邻有效像素行，可能与DET框间距相差一个像素。

未开启换算显示“像素”，开启换算按节点Scale转为mm。图像绘制真实掩膜轮廓和黄色双向箭头，不显示箭头旁黄色数字。缺少测量目标或有效掩膜明确显示无法测量并判NG，不以检测框补造测量；无效缺失值不进入学习样本。不支持的检测项只记录警告并跳过，不中断其它检测项。

## 验证

`Tests/ASTStation1Seg.Tests.ps1`覆盖掩膜几何、ROI偏移、测量、数量、判定、换算、学习隔离、worker序列化和窗体选项。

独立构建目录下的测试程序可执行 `ASTStation1Seg.Tests.exe --infer` 验证真实CPU加载及灰色图推理，或追加产品图完整路径。灰色图零目标不代表产品识别准确率。CPU推理使用本项目现有 `td_det.dll`，仍受厂家设备许可证约束，不采用测试Demo的独立ONNX Runtime引擎。
