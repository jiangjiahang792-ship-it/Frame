# AST工位1分割模型

目标检测节点模型名称选择“AST工位1分割模型”，与原“AST-工位1模型”DET解析独立。

## 配置

- 导入 `Template/TDAI/AST工位1分割模型.ai`；对应的可读配置为 `AST工位1分割模型配置.json`。
- 检测项管理导入 `Template/TDAI/AST工位1分割检测项.items`，在节点选择该检测项集合。
- 默认CPU、SEG、640，置信度0.25，NMS 0.45。配置指向 `D:\MyCode\PublicWook\Fakra_SEG模型测试\FAKRA（AST-CCD1）-SEG20260923\model.onnx`，其它电脑需要重新指定模型路径。
- `.ai`是软件既有加密格式的配置文件，不代表ONNX模型已加密。当前模型为未加密ONNX。
- 示例公差1～99999只用于接入测试，不是生产合格公差，投产前应设置或学习实际公差。

标签顺序必须是：

| ID | 训练标签 | 对应部件 |
| --- | --- | --- |
| 0 | insulation_glue | 绝缘胶 |
| 1 | shielding_mesh | 屏蔽网 |
| 2 | copper_ring | 铜环 |
| 3 | rubber | 胶皮 |
| 4 | fly_line | 飞丝 |
| 5 | aluminum_foil | 铝箔 |

## 测量

模板共16项，默认启用以下两项距离及新增的“铝箔长度”“铝箔宽度”：

1. 绝缘胶顶部最低点到屏蔽网顶部最低点的距离：中央60%有效宽度逐列取首个前景像素，再取最大Y，两侧各排除20%。

“L2_编组切割长度”（旧名“屏蔽网高度”）使用同样的顶部最低点规则，计算胶皮与屏蔽网的 `UpperEdgeLowestY` 差绝对值，不再取屏蔽网自身掩膜高度。两个部件各取最高置信度有效实例；重叠时仍计算该差值，缺少部件或有效取点时显示0并按配置上下限判定。测量箭头跟随这两个取点，比例换算及原有上下限保持不变。该变更仅适用于工位1SEG解析。
2. 绝缘胶顶部到铜环底部的距离：绝缘胶最小有效Y到铜环最后有效Y。

同类多个实例的尺寸、距离使用最高置信度实例；飞丝数量使用全部有效实例。宽高取有效掩膜包围范围，不取模型矩形。

`套筒压接位置`（兼容旧名称“胶皮到铜环的距离”）固定计算胶皮顶部最低点与铜环顶部最高点Y坐标差的绝对值。胶皮保持中央60%有效宽度的顶部最低点；铜环使用完整有效掩膜的最小Y坐标，重叠或上下反向时仍按同一取点计算；缺失有效掩膜或取点时输出0并按上下限判定。箭头端点与测量取点一致。此变更仅适用于SEG模型。

`护套剥离长度`取胶皮与绝缘胶顶部最低点的Y坐标差绝对值。

未开启换算显示“像素”，开启换算按节点Scale转为mm。图像绘制真实掩膜轮廓和黄色双向箭头，不显示箭头旁黄色数字。非数量项缺少测量目标或有效掩膜时输出0，范围包含0则OK，否则NG，不以检测框补造测量；无效缺失值不进入学习样本。不支持的检测项只记录警告并跳过，不中断其它检测项。

铝箔长度取类别5有效掩膜包围范围的Height（Y方向），铝箔宽度取Width（X方向）。多个铝箔实例取最高置信度有效实例；缺失或无效掩膜时输出0并按配置上下限判定，不使用检测框替代。两项支持尺寸换算、补偿、上下限、箭头和自动学习。已有方案需添加并启用这两项，加载更新后的模型配置，并将模型路径指向实际六类SEG模型。

## 验证

`Tests/ASTStation1Seg.Tests.ps1`覆盖掩膜几何、ROI偏移、测量、数量、判定、换算、学习隔离、worker序列化和窗体选项。

独立构建目录下的测试程序可执行 `ASTStation1Seg.Tests.exe --infer` 验证真实CPU加载及灰色图推理，或追加产品图完整路径。灰色图零目标不代表产品识别准确率。CPU推理使用本项目现有 `td_det.dll`，仍受厂家设备许可证约束，不采用测试Demo的独立ONNX Runtime引擎。

L1-S3检测项已删除；编组切割长度继续使用现有L2_编组切割长度算法。
