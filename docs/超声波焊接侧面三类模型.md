# 超声波焊接侧面三类模型

1. 在“检测项管理”导入程序目录下 `Template/TDAI/超声波焊接侧面三类检测项.json`，设置配置名称。
2. 打开AI节点参数，模型名称选择“超声波焊接侧面三类模型”，选择对应的DET模型配置及刚导入的检测项配置，保存参数。
3. 设置实物检测上下限，按需启用尺寸换算及自动学习。模板尺寸范围1～99999仅用于初次接入，飞丝默认0～0；正式检测前需按产品要求调整。

模型类别0为线芯，类别1为焊接区域，类别2为飞丝。尺寸中的“长度”为检测框Width，“宽度”为Height；启用换算后乘以毫米每像素比例，飞丝数量不换算。多个焊接区域分别输出实测值，任意一项超限即为NG。

左右线芯按输入图像中检测框中心X排序，取最左和最右；沿用新增解析文件的约定，只有一个线芯时归左侧，右侧按未检出处理。相同中心的框不会同时充当左右线芯。多个ROI结果合并后也按同一坐标系确定左右，因此一个AI节点应对应一组焊接件。

未检出项当前值更新为0，依照其上下限判定；默认尺寸下限1会使缺失线芯或焊接区域判NG，飞丝为0时判OK。同一检测框的尺寸中有NG时只将该框标红，不影响其他合格框。

自动学习样本按节点参数隔离，切换检测配置或完成学习后清理。缺失尺寸不作为有效学习样本，飞丝按实际数量采样；完成后自动关闭学习。检测结果沿用AI输出结果协议，可供结果绘制、多条件判定和结果发送订阅。
