# 轮廓模板匹配节点

## 三页界面与操作

在流程编辑器“检测”分类添加“轮廓模板匹配”，连接上游节点后双击打开。窗口采用紧凑布局，参数分为三个独立页面。“基础参数”和“运行参数”右侧显示搜索图像和结果；“特征模板”右侧只显示选中模板的裁剪图像和实际轮廓，底部不再重复展示缩略图或结果表。

### 基础参数

- 连线后自动选择最近兼容上游的输出图像，并立即同步节点参数，无需先打开窗口；也可手动指定来源，再点击“刷新订阅图像”，或加载本地图像进行离线建模和预览。具体规则见[节点自动订阅规则](节点自动订阅规则.md)。
- “全图搜索”搜索整幅图像；点击“绘制搜索区域”后，左键拖动矩形、右键确认，Esc取消。这是搜索范围，不会创建模板。
- 节点直接在输入图像的固定搜索区域内匹配，仅保留中心位于区域内部的目标，结果使用原图坐标；不需要订阅位置修正。

### 特征模板

- “创建模板”打开约1040×680的独立“模板配置”窗口：左侧显示图像，顶部提供选择、矩形、椭圆、扇形、多边形、画笔及擦除工具，右侧为区域列表和参数。
- 矩形、椭圆、扇形及画笔：点击工具后在图像上左键拖动，松开立即生成一个可编辑区域，并回到选择工具。可反复点击工具追加区域，已有区域不会被覆盖。
- 多边形：左键逐点添加顶点，双击、右键或回车闭合；Esc取消尚未完成的绘制。
- 点击区域或右侧列表即可选择。拖动区域内部移动，拖动橙色方形柄缩放，拖动上方圆形柄旋转。右侧可精确修改中心、宽高、角度，扇形还可设置起始角和张角。
- “参与组合建模”可以停用单个区域；删除、清空、撤销和重做只作用于区域集合。画布支持Delete删除、Ctrl+Z撤销、Ctrl+Y重做，保留最近40次区域操作。
- 所有启用区域按并集合成一个模板，“创建模板”生成真实轮廓预览；“确定”会先构建尚未更新的区域或创建参数，再把模板返回管理页。未完成的绘制、空区域或建模失败不会保存旧结果。新图像加载后需重新绘制区域。
- 滚轮围绕鼠标位置缩放，中键平移，底部提供“放大”“缩小”“适应”和比例。区域坐标及画笔直径始终按原图像素计算。
- “画笔”用于添加取样区域；“擦除”用于删除已建模型的轮廓，左键涂抹、右键确认，Esc取消，至少保留8个特征。重新构建区域会重新提取轮廓并清空此前擦除记录。
- 可以创建多个模板，列表分别设置名称和启用状态，选中模板后可编辑、删除或导出，也可删除全部。
- “导入模板”接收本节点导出的 `*.contour.json` 模板包，包含源图、创建参数、组合区域、外接框和涂抹记录。整包验证通过后才加入列表，导入的模板获得独立标识。此格式不是第三方软件的专有模板格式。
- 模板创建、编辑确认及列表启停、重命名、删除、导入均即时应用到节点。取消独立编辑器不会覆盖原模板。

### 运行参数

保留原Demo全部搜索参数和默认值（下表）。对所有启用模板执行搜索，合并后按得分排序、按重叠率去重，“最大匹配个数”限制全部模板合并后的总数。未启用的模板不参与搜索。

参数和订阅选择修改后即时生效，无需点击保存参数或保存工程方案。右下角仅保留“执行”和“确定”：执行使用当前参数匹配，结果表显示模板名称、中心、角度和分数；确定仅关闭窗口。预览与生产缓存隔离，在途运行使用独立快照，下次运行读取最新参数。离线图像可用于建模和预览，生产运行需选择有效的上游图像订阅。填写中不完整的配置会保留，执行时提示具体缺项，不会悄悄沿用旧参数。

## 保留的 Demo 创建参数

| 参数 | 默认值 | 范围与含义 |
| --- | --- | --- |
| 金字塔层数 | 0 | 0～6，0 自动 |
| 起始角 / 结束角 | -30° / 30° | -180°～180°，起始角不大于结束角 |
| 角度步长 | 1° | 0.1°～180° |
| 自动对比度 | 开启 | 自动估算模板 ROI 的 Canny 阈值 |
| 手动对比度 | 20 | 1～1024，关闭自动时使用 |
| 最小对比度 | 10 | 0～1024，搜索图像最小梯度阈值 |
| 特征数量 | 300 | 0～10000，0 自动 |
| 极性 | 使用极性 | 使用极性 / 忽略极性 |

创建参数修改后，点击“创建模板”或“确定”重新建模后生效；修改期间不允许把旧轮廓保存为新参数的结果。自动估算后界面显示实际对比度。

## 保存和输出

方案内保存模板列表及每个模板的名称、标识、启用状态、源图、组合区域及其位姿、ROI外接框、确认的建模参数和逐次涂抹遮罩，同时保存输入、搜索区域及运行参数。旧版单模板方案自动转换到模板列表；删除全部后不会从旧字段恢复模板。重新加载不依赖外部图片路径；首次运行恢复模型，随后复用缓存。编辑模型与生产模型隔离，运行直接使用上游 Mat 及其资源租约。

输出包括匹配状态、数量、中心 X/Y、角度、分数、目标位姿列表、动态目标中心坐标、带轮廓绘制信息的输出图像、目标外接矩形、运行耗时及匹配耗时（不含首次建模，包含搜索和结果合并）。分数维持 Demo 的 **0～1**，角度使用图像坐标下的顺时针方向。结果按得分排序，首目标同时作为单值输出。另提供与位姿顺序对应的匹配模板名称列表和标识列表。

至少需要创建并启用一个模板才能运行。没有找到目标时匹配状态为不通过，但节点正常执行完成；输入无效或取消不会沿用上一帧的匹配结果。原生搜索不可在调用中途打断，取消在调用前后检查。

## 构建与验证

主工程使用 .NET Framework 4.8 / x64。原生 DLL 随项目复制到输出目录，无需安装 .NET 8。原生构建方法见 [原生说明](../Native/ContourMatchSource/README.md)。三页节点窗体与独立模板编辑器的控件及布局分别在 `NodeParamFormContourMatch.Designer.cs` 和 `ContourTemplateEditor.Designer.cs`，可在 WinForms 设计器查看。

`Tests/ContourMatch.Tests.ps1` 验证真实原生库、已知位置/旋转/多目标、灰度与彩色及非连续 Mat、模型涂抹恢复、节点订阅、参数即时生效与快照隔离、未保存工程运行、缓存和资源释放，并检查多模板启停、区域限制、旧方案兼容、导入导出、真实三页窗体与独立模板编辑器交互。默认程序集目录为 `bin/ContourMatchValidation`，可用 `-BuildDirectory` 指定其他已编译目录。测试使用合成图像，现场图像的参数仍需按实际产品调试。

## 组合区域与兼容性

组合区域使用原生掩膜入口，仅在创建或恢复模型时生成并集掩膜，不在生产每帧栅格化区域；源图像素保持不变，区域边界不会产生伪轮廓。非完整矩形掩膜不使用完整闭环数量约束，因为分离区域或裁断区域的局部闭环无法与搜索整图直接比较；仍保留掩膜内正向、反向和缺失轮廓评分。原完整矩形模板的闭环校验保持不变。

旧方案没有区域列表时，继续按原矩形模型恢复，并在编辑器中显示为一个可编辑矩形。区域数据随方案及模板包深复制保存。修改本轮功能后需使用随工程更新的 ShapeMatchNative.dll。

新增 Tests/ContourRoi.Tests.ps1 验证多区域松开生成、选择/移动/缩放/旋转、各类掩膜、撤销重做、区域启停、组合建模和持久化；默认独立输出目录 bin/ContourRoiValidation。

金字塔搜索按当前层模板跨度限制角度抽样间隔，避免远距离组合区域因跳角过大而丢失原图姿态。该约束同时用于粗搜索和逐层精修，快速模式和最低分数的含义保持不变。

自动金字塔下，使用极性、跨度至少 768 像素、选区面积小于外接框 60% 且没有重复孔洞拓扑约束的组合模板，采用低分辨率候选搜索和原图稀疏梯度配准。候选层最多 192 像素跨度，原图精修检查梯度方向、分区覆盖及最低分数；结果按最终分数重新排序和去重。指定金字塔层数、忽略极性、完整矩形或依赖重复孔洞数量的模型沿用完整搜索路径。擦除区域保守投影到候选层，避免细小擦除笔画被缩放丢失。

`Tests/ContourSelfImage.Tests.ps1 -SolutionPath <方案路径> -BuildDirectory <编译目录>` 从指定方案读取建模原图，验证原始参数的生产会话、缓存复用、不同搜索层数以及平移旋转后的识别；不会修改方案。该脚本用于包含一个启用模板、全图搜索、支持 -7°～13° 的现场回归方案。原生测试另有不依赖现场图像的大跨度三个矩形区域用例，覆盖原图、平移和旋转。
