# 端子角度节点

本节点使用现有 OpenCvSharp，在两个手工 ROI 中定义一个端子和一个基座参考位置，输出端子相对图像固定垂线的角度。沿用此前确认的水平 180°／垂线 90° 基准。

## 使用步骤

1. 在“测量工具”中添加“端子角度”，连接上游图像源。
2. 先运行上游图像节点，再双击本节点，在左侧“输入图像”分组选择上游“输出图像”，点击底部“刷新图像”。刷新直接读取已有输出，不重新触发相机或运行流程。
3. 点击“绘制端子”，拖框包住有效金属端子，上下贴近有效主体、左右留出背景；默认要求主体高度覆盖 90%、左右留 3 像素。
4. 点击“绘制基座”，在下方基座位置拖框。框中心只决定基准线的显示位置，方向始终水平／垂直，不根据基座纹理拟合角度，也不输出偏移。
5. 点击“执行”，图像结果仅显示蓝色端子中线、青色基座垂直中线及角度文字，不显示 ROI 框、名称、控制点或拟合矩形。“确定”始终关闭参数窗口，不要求先刷新图像、绘制区域或取得定位；有效编辑会保留，非法输入不覆盖原已保存参数，也不阻止关闭。测量过程中仍可点击确定取消预览并关闭。

默认蓝色通道阈值 220，高斯尺寸 3，端子矩形宽度 25～105 像素。尺寸均为节点输入图的像素。更换倍率或裁剪尺寸时，在左侧“分割参数”和“质量检查”分组调整参数。

图像中的端子角度保留一位小数（如 +5.0°、-1.2°、0.0°），单目标和多目标显示一致；计算及订阅输出仍保留原始精度。

在两版“ROI 结果绘制”的文本项中订阅“端子角度”时，同样固定显示一位小数，例如 5.0、-1.2、0.0；多目标数组逐项采用相同格式，失败目标保留空值。数值订阅仍为 double?，供后续计算使用，显示格式由来源结果的 ISubscriptionTextFormatter 接口提供。

界面沿用卡尺工具的灰色背景、原生分组和按钮，默认 900×560，最小 860×520。左侧仅保留输入图像、位置修正、分割参数和质量检查。没有目标选择、端子/基座坐标输入和测量结果面板；区域直接在图像上画，角度、失败原因和操作提示直接叠加到图像。

标题栏按文字与图标自动调整高度，订阅分组预留完整下拉框空间。底部为“绘制端子、绘制基座、刷新图像、执行、确定”五个按钮；确定后隐藏可复用的参数窗口。两版 ROI 结果绘制订阅本节点时，也只绘制两条中线，不添加中心十字或 ROI 标签。

两个 ROI 分别定义端子和基座参考位置。未启用修正时测量一个区域；启用修正后，同一组区域按照上游修正列表作用到全部模板目标，与卡尺节点一致。新画搜索框保持水平/垂直；拟合方向独立计算，结果只显示中线。区域边框只在编辑阶段显示，执行后清除。

## 位置修正

勾选“启用修正”，订阅上游“位置修正信息列表”。和卡尺一样，绘制时按 ROI 中心自动关联所在定位目标，运行时按列表顺序测量全部目标。没有手选目标。失败目标保留位置和原因；无定位目标时显示失败，不沿用旧结果。旧方案默认关闭修正。

先运行定位和位置修正节点，再刷新图像。新画矩形保存当前画面坐标和当时的定位快照，同一帧的修正严格为恒等，因此不会被模板已有角度带斜。后续图像只应用“当前位姿 × 绘制位姿的逆变换”；下一帧实际旋转、平移和缩放仍然有效。旧区域缺少绘制快照时保留原基准语义，重新绘制后使用新语义。修正输出必须与订阅图像使用同一坐标系，尤其要核对裁剪后的图像坐标。

刷新或切换图片会取消旧绘制、清理动态框，并使旧鼠标回调失效；已有区域作为静态轮廓显示，需要编辑时点击相应绘制按钮重画。定位和预览图一起复制，参数窗口不会用更新后的定位去解释旧图。先在弯端子图绘制，再切到直端子图重画，新框仍保持水平/垂直。

测量仅对端子局部区域做仿射采样，调用现有算法后将矩形和长轴转换回当前原图。角度仍相对当前图像固定垂线，顶部右倾为正，不扣除定位旋转角；基座基准线跟随位置但保持水平／垂直。未开启修正或恒等修正时沿用原算法，不增加图像重采样。

## 输出

| 输出 | 含义 |
|---|---|
| 测量成功 | 存在目标且全部目标测量成功，不是产品合格判定 |
| 端子角度 | 保留第一目标订阅兼容；单位度，顶部向右为正，第一目标失败或无目标时为空 |
| 多目标端子角度结果 | 全部目标的角度、成功状态、失败原因和叠加，顺序与上游列表一致 |
| 测量状态 | 成功说明或失败原因 |
| 算法耗时 | ROI 内算法毫秒，不含采图、解码、显示 |
| 算法结果 | 框架可订阅的端子中线、基座垂直中线与角度文字叠加层 |
| 输出图像 | 借用上游原图并携带叠加层，图像像素不改变 |

没有目标或任一目标质量不足时，`测量成功=false`；单目标失败只影响对应结果项。第一目标成功时兼容标量角度仍有值，下游应先判断测量成功或订阅目标结果列表。输入或订阅异常按框架运行失败处理；取消、禁用和异常都会清除上轮角度。

## 实现与资源

- 核心接口 `ITerminalAngleMeasurer`，实现 `OpenCvTerminalAngleMeasurer`。
- 仅读取端子 ROI：蓝色通道 → 显式 sigma 高斯滤波 → 低灰度分割 → 全部外轮廓 → 逐行提取最左/最右边界点 → 左右边界直线拟合。
- 不再只取最大连通域；端子被反光或阴影分割成多段时，多段左右外轮廓共同参与拟合。过宽毛刺行、触边、宽度、高度覆盖和长宽比仍会被质量检查拒绝。
- 根据左右拟合边界的平均方向生成端子中线，统一向下，再用 `atan2(-dc,dr)` 计算相对垂线倾角。显示用四角由中线和宽度中位数生成，不再依赖 OpenCV 矩形 Angle 的宽高交换约定。
- 不执行基座图像定位、自身弯曲、偏移、磁盘读取或批量报告，因此耗时口径不同于之前完整 Demo。
- 输出持有上游图像租约，已有灰度缓存可复用；缺失时不为此节点生成整幅灰度图。临时 Mat 全部释放，预览图由窗体独立持有。
- 新节点已加入枚举、两处工厂、工具箱、CPU 算法调度分类与显式工程编译项。类型名作为方案兼容契约保留。
