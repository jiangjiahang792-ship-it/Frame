# AST-工位1模型

目标分类节点新增 `AST-工位1模型`，采用 DET 检测，输入尺寸 640。解析入口为 `ASTStation1Parse.Parse`，沿用 `RL12Parse` 的检测项 switch、提取、上下限判断、矩形/文本输出、流程计数和自动学习结构。

## 配置方式

1. 在检测项管理中导入 `Template/TDAI/AST-工位1检测项.items`。
2. 在目标分类参数窗体的模型配置中选择 `Template/TDAI/AST-工位1模型.ai`。
3. 模型名称下拉选择 `AST-工位1模型`，检测项配置选择刚导入的配置，设置图像订阅并保存。
4. 按现场合格标准设置各项上下限；模板的 `1～99999` 仅用于初始化，不是产品公差。可沿用自动学习及物理值转换功能。

模型配置指向用户提供目录中的 `D:\项目\AST-Fakra\软件数据\Model\FAKRA（AST-CCD1）\work1.onnx.encrypted`，设备默认 GPU，置信度和 NMS 阈值均为 0.5。更换部署路径或推理设备时，用现有 AI 配置工具编辑 `.ai` 文件。旁边的 `AST-工位1模型配置.json` 是便于核对的明文内容，参数窗体应选择 `.ai` 文件。

## 类别和测量

| 类别编号 | 标签 | 含义 |
| --- | --- | --- |
| 0 | insulation_glue | 绝缘胶 |
| 1 | shielding_mesh | 屏蔽网 |
| 2 | copper_ring | 铜环 |
| 3 | rubber | 胶皮 |
| 4 | fly_line | 飞丝 |

| 检测项 | 当前测量口径 |
| --- | --- |
| 胶皮到铜环的距离 | 胶皮框与铜环框沿图像 Y 轴的上下边缘间距 |
| 胶皮到屏蔽网的距离 | 胶皮框与屏蔽网框沿图像 Y 轴的上下边缘间距 |
| 胶皮到绝缘胶的位置 | 胶皮框与绝缘胶框沿图像 Y 轴的上下边缘间距 |
| 屏蔽网高度、宽度 | 类别1检测框的 Height、Width |
| 铜环高度、宽度 | 类别2检测框的 Height、Width |
| 绝缘胶高度、宽度 | 类别0检测框的 Height、Width |

三个距离/位置项按用户确认的竖直方向测量。胶皮在目标下方时计算 `胶皮.Top − 目标.Bottom`，胶皮在目标上方时计算 `目标.Top − 胶皮.Bottom`，框在 Y 轴投影重叠或接触时值为0；X方向的间隙不参与距离值计算。多个目标分别输出明细，每个部件选择中心最近的胶皮框作为参考；复杂多工件画面应先通过 ROI 限定对应工件。

默认单位是原图像素。启用物理值转换后，九项实测值均乘以节点比例。缺少目标或胶皮依赖时输出0，按当前上下限判定，与 RL12 的缺失零值语义一致。未检出的值不参与尺寸自动学习。禁用项不输出；同一矩形涉及多个检测项时，任一项 NG 则该矩形标红。

标签4保留在模型配置中，本次按用户要求只提供九个尺寸项，没有增加飞丝检测项。自动学习样本按节点参数隔离，学习完成或切换检测配置后清理，防止不同节点混用。AST学习完成事件同样按参数实例通知，避免不同流程的同名节点互相关闭学习。

## 离线验证

运行 `Tests/ASTStation1.Tests.ps1`，默认使用 `bin/ASTStation1Validation` 下的独立构建。验证真实解析器的尺寸、距离、缺失值、颜色、学习、配置加解密、语言资源及真实参数窗体保存/恢复，并生成 `AST-parameters.png`。离线测试不连接设备或加载现场模型。
