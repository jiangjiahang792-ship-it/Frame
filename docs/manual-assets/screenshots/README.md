# TDJS-Vision 图文说明书截图素材

本目录保存从 `bin/x64/Release/机器视觉AI检测系统V1.0.exe` 实际运行界面采集的截图。

## 文件命名

截图使用“序号-分类-模块-界面.png”格式，例如：

`001-平台基础-软件启动-主窗口.png`

## 使用规则

- 截图必须来自当前 Release 程序的实际界面。
- 不伪造相机、PLC、Modbus、TCP、串口或 AI 的成功运行状态。
- 涉及账号、密码、序列号、IP、产品数据时避免采集或在文档中隐藏。
- 三维内容只保留连接、取图和显示界面，不扩展未实现的三维算法。
- `screenshot-manifest.csv` 记录截图与功能模块的对应关系和受限原因。
