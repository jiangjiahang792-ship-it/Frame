# AST-工位3模型

目标分类模型名称选择 `AST-工位3模型`，推理配置为 **CPU、DET、640**。解析入口为 `ASTStation3Parse.Parse`，用于工位3/5共用三类模型目录 `FAKRA（AST-CCD3-CCD5）20260916`。

## 配置

1. 在检测项管理导入 `Template/TDAI/AST-工位3检测项.items`。
2. 在目标分类参数界面选择模型配置 `Template/TDAI/AST-工位3模型.ai`。
3. 模型名称选择 `AST-工位3模型`，检测项配置选择已导入的工位3配置，设置图像来源并保存。
4. 尺寸项模板默认上下限为 `1～99999`，飞丝数量默认上下限为 `0～0`。启用物理值转换时，尺寸项乘以节点比例，飞丝数量不做换算。

配置实际模型路径为 `D:\项目\AST-Fakra\软件数据\Model\FAKRA（AST-CCD3-CCD5）\FAKRA（AST-CCD3-CCD5）20260916\model_encrypted.onnx`。设备为 CPU，加密模型标志为 true，置信度与 NMS 阈值均为 0.5。`AST-工位3模型配置.json` 用于查看配置内容，参数界面应选择加密配置 `.ai`。

## 类别映射

| 类别 | 模型标签 | 含义 |
| --- | --- | --- |
| 0 | female_copper_wire | 露线芯 |
| 1 | closed_opening | 压接区域 |
| 2 | fly_line | 飞丝 |

解析器也供客户工位4使用，现支持新增类别3：`closed_opening-ng`（压接不良）。使用该类别时应加载包含四类标签的新模型配置；本次仅增加解析及检测项模板，未改写原有三类模型配置或模型文件。

## 六个检测项

| 检测项 | 计算方式 |
| --- | --- |
| 露线芯宽度 | 类别0检测框的 Width，X 方向尺寸 |
| 露线芯高度 | 类别0检测框的 Height，Y 方向尺寸 |
| 压接区宽度 | 类别1检测框的 Width，X 方向尺寸 |
| 压接区域高度 | 类别1检测框的 Height，Y 方向尺寸 |
| 飞丝 | 类别2检测框数量，数量型检测项 |
| 压接不良 | 类别3有效检测框数量，数量型检测项；默认上下限0～0 |

压接不良未检出时输出0，正常检测下默认检出即判NG，检出框按判定着色；数量不乘尺寸比例、不显示mm、不绘制尺寸箭头。检测项必须在所选配置中启用，旧现场方案不会自动增加该项。自动学习期间沿用原有默认OK策略。

缺少某类目标时，仅对应检测项输出0，其他检测项继续解析。飞丝按检出数量输出，缺少飞丝时数量为0。缺失值按配置上下限判定，不参与尺寸学习。同框多个检测项任一 NG 时绘制为红色。

## 验证

`Tests/ASTStation3.Tests.ps1` 默认使用独立构建 `bin/ASTStation3Validation`，直接验证真实解析器、可导入模板/配置、CPU标志、类别顺序和真实参数窗体保存恢复，不加载现场模型或连接设备。
