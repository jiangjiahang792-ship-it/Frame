# AST-工位2模型

目标分类模型名称选择 `AST-工位2模型`，推理配置为 **CPU、DET、640**。解析入口 `ASTStation2Parse.Parse` 沿用工位1和 RL12 的检测项 switch、结果提取、上下限判断、绘制、流程统计及自动学习结构。

## 配置

1. 在检测项管理导入 `Template/TDAI/AST-工位2检测项.items`。
2. 在目标分类参数界面选择模型配置 `Template/TDAI/AST-工位2模型.ai`。
3. 模型名称选择 `AST-工位2模型`，检测项配置选择已导入的工位2配置，设置图像来源并保存。
4. 尺寸项模板默认上下限为 `1～99999`，飞丝数量默认上下限为 `0～0`。请按现场工艺设置公差或使用自动学习。启用物理值转换时，尺寸项统一乘以节点比例。

配置实际模型路径为 `D:\项目\AST-Fakra\软件数据\Model\FAKRA（AST-CCD2）\model_encrypted.onnx`。用户提供的 `model\_encrypted.onnx` 当前不存在，采用同目录实际模型文件。设备为 CPU，加密模型标志为 true，置信度与 NMS 阈值均为 0.5。`AST-工位2模型配置.json` 用于查看配置内容，参数界面应选择加密配置 `.ai`。

## 九个检测项

| 检测项 | 计算方式 |
| --- | --- |
| L1-S2(端子先端位置) | `Abs(铜环.Bottom − 端子头.Top)` |
| 出线芯宽度 | 类别1检测框的 Width，X 方向尺寸 |
| 出线芯长度 | 类别1检测框的 Height，Y 方向尺寸 |
| 编组反转代-1 | `Abs(胶皮.Top − 屏蔽网.Top)` |
| 编组反转代-2 | `Abs(胶皮.Top − 屏蔽网.Bottom)` |
| L5_绝缘体长度 | `Abs(胶皮.Top − 绝缘胶.Top)` |
| 飞丝 | 类别6检测框数量，数量型检测项 |
| L6_箔剥宽度 | 类别2检测框的 Width，X 方向尺寸 |
| L6_箔剥长度 | 类别2检测框的 Height，Y 方向尺寸 |

距离项始终测量指定边缘，取 Y 坐标差的绝对值。即使两个检测框重叠，也继续使用指定边；只有两条边 Y 坐标相同时距离才为0。坐标采用原图坐标，默认单位为像素。

多目标分别输出明细，每个目标关联中心最近的铜环框或胶皮框，同距离时按坐标稳定选择。缺少铜环时端子先端位置为0，缺少胶皮时三项胶皮距离均为0，缺少屏蔽网时两项编组反转代均为0，缺少绝缘体时L5_绝缘体长度、L6_箔剥宽度和L6_箔剥长度均为0；铝箔不参与当前九项检测。缺少其中一个目标仅将对应检测项输出0，仍继续输出其他检测项。飞丝按检出数量输出，缺少飞丝时数量为0。缺失值按配置上下限判定，不参与尺寸学习。同框多个检测项任一 NG 时绘制为红色。

检测项配置中若存在代码尚未接入的名称，解析器会记录 Warn 日志，提示“代码里面没有判断，已跳过该检测项，其它检测项继续检测”，并继续解析其它已支持检测项；该未知项不输出伪造结果。

当前工位2模板使用 `出线芯长度` 作为结果键，解析器仍保留旧名称 `露线芯长度` 和内部键 `DetectItem.ExposedCoreLength` 兼容既有方案。新增检测项翻译使用中文键。自动学习数据和完成通知按节点参数实例隔离，兼容不同流程同名节点。

## 验证

`Tests/ASTStation2.Tests.ps1` 默认使用独立构建 `bin/ASTStation2Validation`，直接验证真实解析器、可导入模板/配置、CPU标志、类别顺序和真实参数窗体保存恢复，并生成 `AST2-parameters.png`。回归包括指定边缘、重叠、反向、缺失、物理换算、多目标与学习隔离，不加载现场模型或连接设备。
