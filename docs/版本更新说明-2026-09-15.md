## 主要更新

### 1. 相机采集与断线恢复

- 改进海康原生 SDK 回调、图像转换和资源释放，按相机独立转换，减少多相机之间的等待。
- 补充生产取图票据、硬触发帧缓存、迟到帧隔离与单流程先进先出处理。
- 修复软件启动后首次取图容易超时的问题：首个生产帧增加一次启动宽限，后续恢复配置的正常超时。
- 单次软件触发取图超时支持恢复；相机掉线后自动重连，隔离该相机旧帧和票据，不主动停止整个方案。
- 以方案中保存的曝光、增益和触发参数为准，避免相机离线时读取 SDK 导致方案恢复失败。

### 2. PLC、Modbus 与外部信号

- 新增基恩士 Nano OverTcp 和 KV300/Older 通信，补齐 DM 字寄存器位读取及字内 bool 写入。
- PLC、Modbus 主站支持后台恢复连接，增加“断开并停止重连”入口。
- 修复多条件判定对 PLC 读取结果的订阅。
- 外部发送节点采用到达即发：PLC 写入、Modbus 写入、串口、相机 IO 和结果发送不等待前序工件；保留参数快照、取消与实际发送结果检查。
- 相机 IO 保留同步/异步模式及保持、复位配置；TCP 等待实际发送和已配置的响应接收。
- 使用注意：直接发送不保证跨工件顺序，同一设备地址或线路的并发写入需要方案自行协调。

### 3. 流程与结果发送

- 流程组扩展至 40 组，保持旧组别编号及方案保存兼容。
- 新增“结果发送”节点，支持四则运算、AI 检测、测量和多条件判定结果，支持 PLC/Modbus、多种数据类型及单值、多值、汇总发送。
- 检测项在未运行、重启后及禁用状态下均可显示和订阅；增加类型、容量、地址重叠及失败行检查。
- 未检出时按类型发送默认值：数值为 0、bool 为 true、字符串为“无效”。

### 4. 图像裁剪与 ROI 绘制

- 裁剪参数页改用通用图像显示控件，支持矩形拖动、缩放、旋转、删除和清空。
- 旋转 ROI 直接裁剪并摆正为紧凑矩形；整数零度矩形保留直接裁剪路径。
- ROI 部分或完全越界时，按图像边缘像素补齐，保持所设宽高和角度。
- ROI 结果绘制支持 0、90、180、270 度旋转；修复一个检测项 NG 导致全部 ROI 变红的问题。

### 5. AI 检测与训练

- 接入超声波焊接侧面三类模型，提供左右线芯长宽、焊接区域长宽和飞丝数量等七个检测项、导入模板及说明。
- 补充多端子和 RL12 解析的端子数量公共判定及结果文本。
- 改进大模型、无监督训练的少样本处理与默认阈值策略，修复单张 NG 导致的训练拆分问题，增加失败恢复和环境预检。
- 增加 YOLO 独立进程与共享内存传图实现及相关验证，保留其适用配置与现场验证要求。

### 6. 性能、测量与诊断

- 增加资源预算、CPU 调度、图像生命周期管理、图像保存保护和按窗口刷新限流。
- 更新模板匹配、Blob 分析、卡尺测量和图像结果订阅相关实现。
- 补充相机帧跟踪、流程耗时诊断、专项测试及性能对比工具。
