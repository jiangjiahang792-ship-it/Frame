# 新版本轮廓模板匹配

在检测分类选择“新版本轮廓模板匹配”。旧“轮廓模板匹配”节点及其方案保持原实现。

操作沿用原节点的基础参数、特征模板、运行参数三个页面：订阅图像或加载离线图片，打开创建模板，绘制矩形、椭圆、扇形、多边形或画笔组合区域，创建并确认。支持轮廓擦除、撤销区域编辑、多模板启停、导入导出及方案恢复。新增控件均位于对应 Designer 文件。

创建参数中“轮廓算法”默认第二版（OpenCV2），可选择第一版。每个模板独立保存算法版本。改变算法或参数后重新建模，确认后立即生效。

新增横向、纵向缩放容差，默认各 0.10，表示搜索 0.90～1.10 的尺度；设为零锁定该方向尺度。轮廓高低阈值默认 40/20，高阈值必须大于低阈值且不超过255。支持最小轮廓长度及搜索超时，超时零为不限时；超时是阶段间协作检查，不能保证精确截止时间。

金字塔层数在创建参数配置。搜索保留角度范围、最低分数、最大匹配数和重叠率；始终使用 Demo 自带精修，隐藏旧算法的快速/平衡/高精度、亚像素开关和搜索层数。没有沿用旧算法的自动对比度和特征数量选项，避免参数显示与实际行为不一致。

多模板依次搜索后统一去重和限数，输出中心、角度、分数、模板身份、尺度及变换后的轮廓。定位中心统一为 ROI 中心；显示宽高包含缩放，位姿列表的 ScaleX/ScaleY 保留实际比例，可供位置修正使用。

新版模板包标识为 `TDJS.NewContourTemplates`，与旧节点模板包隔离。保存的是源图、区域、参数、擦除记录，加载时重建并缓存原生模型。搜索角度改变后的首次运行可能包含缓存重建耗时。取消在原生调用前后检查，算法超时失败不返回部分结果。

测试：`Tests/NewContourMatch.Tests.ps1`；构建说明：`Native/NewContourMatchSource/README.md`。
