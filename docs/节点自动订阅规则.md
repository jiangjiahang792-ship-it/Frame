# 节点自动订阅规则

新增节点必须复用 `NodeSubscription`，通过 `SetExpectedValueType<T>()` 或 `SetInputContract(...)` 声明输入，再调用 `Init(node)`。所有控件继续在 Designer 中声明和初始化。禁止在节点中自行编写“取流程第一项”或按画布坐标寻找来源的逻辑。

## 连线与选择

- 新建订阅沿当前流程的反向连线逐层查找，优先直接上游，再查间接上游。
- 每层按节点编号稳定排序；取第一个能提供兼容公开输出的节点，再取端口目录中的第一个兼容输出。同层有多个业务上可选来源时，用户可手选。
- 图像源 → 图像裁切 → 卡尺：卡尺输入选择图像裁切的输出图像。
- 图像裁切 → 位置修正 → 卡尺：图像输入跳过没有图像输出的中间节点，位置修正输入选择最近的修正信息列表。
- 类型和集合形态都由统一输入契约检查。图像、位置修正、数值、布尔、文本及其他标准订阅使用相同规则，不按节点名称硬编码。
- 找不到兼容来源时保持空，不错误选中其他类型；只建立订阅关系，不自动运行上游或打开可选功能。
- 自动选择会随连线和输出定义变化重新计算；明确手选、旧方案恢复的指定路径优先保留。保存重载后，已有路径作为指定配置保留，不迁移现有方案的业务来源。
- 手选来源临时断线时保留路径，重连后恢复；用户主动清空后保持空。不存在的旧输出保留缺失提示，不静默替换成第一项。

## 参数与运行

`SetText` 恢复空参数时采用公共自动选择，避免打开新节点窗口把连线结果覆盖为空。`ClearText` 表示用户明确清空，两者语义不同。

轮廓模板匹配创建时建立参数快照，并通过 `SelectionChanged` 同步订阅，连线后无需先打开窗口即可记录输入来源。恢复窗口只在订阅实际变化时更新快照，保留既有模板和数值精度。

其他仍采用“确定保存”方式的节点，连线后输入控件即填好，算法 ROI、阈值等参数仍按各节点的原有保存流程配置。新增使用参数快照的节点必须处理 `SelectionChanged`，不能只更新下拉框而遗漏运行参数。

公共策略由 `ISubscriptionSourceSelector` 定义，默认实现为 `NearestSubscriptionSourceSelector`。使用反向邻接表和广度优先遍历，只在配置变化时查找；逐帧取值不重新遍历流程图，也不复制图像。

## 接入验证

- `Tests/SubscriptionConsumerContracts.Tests.ps1` 按真实 `NodeSubscription` 字段声明检查输入契约，覆盖自定义控件名称和 Designer 部分类型。
- `Tests/SubscriptionAutoSelection.Tests.ps1` 使用真实卡尺、轮廓和裁切节点检查连线后选择、空参数恢复、图像实际取值、位置修正列表、数值/布尔/文本、新输出接入、改线、断线重连、手选保护及环路。
- 增加节点时应验证连线前后、首次打开参数界面、保存重载及实际运行使用的来源一致；仅验证下拉框文字不足以证明运行正确。
